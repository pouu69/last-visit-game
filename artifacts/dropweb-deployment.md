# Dropweb 배포 기록

2026-10-28. **폐관 후의 박물관 - Game**을 Dropweb에 비공개로 배포했다. 인증된 계정에서 새 게임과 초대장 대화를 실제 Chrome으로 확인했다.

- 프로젝트 공유를 위해 배포 주소와 사이트 ID는 문서·메타데이터에서 제거했다.
- 최종 배포 폴더: `output/dropweb-compatible/`. 보관용 [ZIP](dropweb-game.zip), [배포 메타데이터](dropweb-deployment.json).
- 원본 `dist/`의 `.mjs`를 `.js`, 원고 `.md`를 `.txt`로 바꾸고 참조 경로·빌드 목록을 다시 계산했다. 게임 원본·원고 내용·저장 형식은 그대로 유지했다.
- Dropweb 상세 조회의 이름·비공개 설정·파일 수 31개를 확인했다. 원고·모듈 등 30개 자산은 배포 파일과 SHA-256이 일치한다. HTML은 Dropweb의 삽입 부분을 제외하면 원본과 일치한다. 익명 접근은 HTTP 302로 전환되며 인증 접근은 정상 응답한다.
- 실제 배포 주소에서 Three.js 캔버스, 1팀 새 게임, 초대장 조사와 다음 메시지를 실행했다. 페이지 오류·HTTP 오류가 없었다. [배포 화면](../output/playwright/dropweb-game.png).
- 기존 로컬 진행은 다른 사이트 주소에 자동 공유되지 않는다. 로컬에서 기록을 내려받아 이 배포 주소에서 불러온다.

스킬 CLI의 curl 파서가 코드 블록 뒤의 홈페이지 링크를 업로드 주소로 덮어써 첫 요청이 실패했다. 설치된 스킬은 수정하지 않고, 도구가 반환한 curl 코드 블록만 해석해 같은 업로드 요청을 실행했다. 첫 업로드 뒤 `.md` 원고 7개가 서버에서 제외된 것을 확인하여 `.txt`로 변환하고 같은 사이트에 갱신했다. 최종 충돌 수정 배포에는 31개 파일이 모두 있다.

2026-10-28 충돌 갱신: 벽·가구·복제 모델·인물·수레 판정을 반영했다. 전체 74개 검사와 핵심 Chrome 이동을 확인한 빌드를 같은 사이트 ID에 갱신했다. [배포 파일 검증](dropweb-collision-verification.json), [충돌 검토](collision-review.md), [개인정보 검토](security-review.md).
