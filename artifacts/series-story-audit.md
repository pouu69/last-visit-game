## 전체 서사의 고정 사실

옛 왕복길은 출발 12명, 귀환 대열 11명인데 완료 처리됐다. 열두 번째인 정연도 무사히 귀가했지만 모임이 끝났다는 안내를 받지 못했다. 이후 모임은 열리지 않았다. 역·극장·수리소에서 각각 동선, 신원·녹음, 장비·안내 불일치를 확인한다.

정연은 공연 뒤 강변 위쪽에서 늦은 참석자를 기다렸다. 대열은 반대쪽 입구로 귀환했고, 녹음의 마지막 박수는 종료 안내가 아니었다. 안내등은 고정형으로 용도가 바뀌었지만 인쇄물의 ‘불이 꺼지면 귀환’은 남았다. 문정은 돌아온 대열만 확인하고 도장을 찍었다. 하나의 사람이나 장비만 범인으로 결론 내리지 않는다.

나래의 원래 종이배 모임은 1편 결과대로 이미 열린다. 새 목표는 **한 달 뒤 처음 오는 사람도 함께할 왕복길 모임**이다. 플레이 시간 때문에 마감이 지나가거나 뒤에 방문한 장소의 물건이 파기되지 않는다. 박물관·철도 재개관도 자동 성과가 아니다.

## 1편: 폐관 후의 박물관

- 공간: 기존 연결된 박물관의 로비·전시·기록·관장실·안뜰·반환실 등의 현재 구현을 유지한다.
- 인물: 방문객 집단, 안내 로봇 모로, 관장 윤서, 기증자 강나래(연락).
- 시작: 초대장을 읽고 윤서를 만나 사라진 제1호 종이배 조사.
- 사건: 모로가 유효한 반환 요청으로 배를 이동했으나 반환 장치가 고장났다. 윤서는 반환 규약을 숨기고 나래의 사연을 각색했다. 침수된 두 분리 함에서 배·원본 장부를 회수하고 모로의 전원을 고려한다.
- 한 경로는 11번 결정(일반 9+미션 2), 전체 분기는 선택 장면 21개와 엔딩 6계열. 기존 장면을 새 편의 한 챕터로 축약하면 안 된다.
- 종료: 마지막 행동과 상태별 후일담을 모두 읽은 후 연작 연결. 배 상태·장부 상태·모로 전원·봉인·시정 근거를 유지한다.

연결부에서 나래의 해당 엔딩별 초대, 옛 왕복 접수표, 세 장소의 사전 협조를 보여준다. 모로 동행/맡기기를 선택한다. 방전은 다음 날 충전으로 회복할 수 있으나 봉인을 자동 해제하거나 추가 로그를 얻지 않는다. 비동행 시 모로의 현장 대사와 퍼즐 역할을 제거해도 진행된다.

- 인물: 나래·문정·소희·이든·처음 오는 연우, 참석 의향을 확인한 경우만 정연, 동행 시만 모로. 윤서는 메시지.
- 진행: R50 도착/옛 사건 정리→R51 현장 역할→R52 운영안→R53 한 건 보완과 연우 맞이→R54 실제 실행/귀환/정리→마지막 종료 확인.

- R51: A 도착 안내 문구와 연우 맞이 / B 의자와 통로 / C 보조 신호 위치 / D 귀환 담당·물품 인계. 이 조사는 기존 미완료를 채우지 않는다.
- R52: A 한자리 / B 공개 왕복 / C 세 접점 합류 이동 / D 작은 첫 왕복+다음 인계. 현재 부족한 준비를 선택 전에 표시한다.
- R53: 연우가 입구에서 기다린다는 메시지→시작을 멈추고 R51 역할을 실제 실행→**한 항목만** 보완(A 길, B 신호, C 선택 장비, D 인수). 이미 완료 항목 재확인도 다른 항목은 채우지 않는다.

### 최종 준비식과 분기

- 길 = 역 최종 A/D면 동행 확약, B/C면 왕복 현장 확인. R53-A로 선택 방식에 필요한 길 준비만 보완.
- 신호 = 공개 신호 시험. R53-B로 보완.
- 장비 = 고정/이동등은 선택 형태 준비, 손표지/등 미사용은 주간 조건. R53-C도 새 전기등을 지급하지 않는다.
- 인수 = 이든 다음 점검 교육. R53-D로 보완하며 오늘 공개 왕복 조건과 별개.
- `publicReady = 길 AND 신호 AND 장비`.
- `mobileReady = publicReady AND 수리소최종∈{B,C}`.

축소 방향의 추가 결정을 다시 읽지 않는다. 실행은 실제로 하고 해당 엔딩으로 간다. D 엔딩 이름이 독립 운영 완성을 뜻하지 않는다. 인수 미완료면 태오가 보관·점검 책임을 유지하고 이든은 교육 동행이다.

마지막은 반드시 출발·정지·귀환·정리를 수행한 뒤 사람별 종료/따로 귀가를 확인한다. 대열 11명만 보고 완료했던 과거와 대응한다. 나래는 사용한 종이·대야, 문정은 표지, 소희는 음향·카드, 인계 담당은 장비를 거둔다. 원래 배를 새 소지품처럼 사용하지 않는다.

## 엔딩 기반 방문과 전환 계약

`completed`를 저장하고 현재 엔딩 우선순위에서 미완료 첫 편을 고른다. 2·3·4 완료면 5. 이미 간 장소에 떠난다고 말한 뒤 취소하지 말고 나래의 회신으로 해당 부탁 문장부터 교체한다. 모든 6순서(234,243,324,342,423,432)를 지원한다.

전환 연출은 원고에 정해진 특정 카메라 애니메이션이 아니라 구현 판단 영역이다. 다음을 권장하며, 사실로 둔갑시키지 않는다.

- 박물관 종료→다음 날 초대: 퇴장·폐관 조명→편지/회신과 시간 경과→선택 목적지로 걷기. 모로 동행과 충전 처리.
- 역 출발: 표지 보관/인계 및 문정의 안내 동작→뒤뜰 보행로를 따라 이동.
- 극장 출발: 선택 음원·카드 정리, 무대 통로로 퇴장. 개인 독창은 극장 문을 넘으며 배경음으로 계속 재생하지 않는다.
- 수리소 출발: 출고 물품 또는 대기 꼬리표를 보여주고 작업장 문으로 이동. 선택하지 않은 장비를 손에 들리지 않는다.
- 마지막 중간편→5편: 준비 기간 후속 회신을 한 번 읽고 한 달 뒤 낮 시간의 모임으로 전환. 담당자와 위쪽 쉼터까지 실제 동행.
- 모든 전환: 중복 실행 방지, 출발/도착 좌표·방향, 카메라/오디오 교차 연결, 입력 복구, 저장·재개, 미완료 장소만 목적지로 표시.

## 1편 상태의 후속 회신

세 중간편을 모두 마친 뒤 5편 전에 한 번 적용한다. 과거 결과와 후속 회복은 별개 기록으로 유지한다.

- E1 이미 띄운 원래 배는 다시 소지하지 않는다.
- 밀봉 배: 사흘 뒤 전문가·윤서 입회 개봉→늦은 반환. 첫 모임 성공으로 소급하지 않는다.
- 손상 배: 나래가 허락한 보수→흔적이 남은 반환. 온전했던 것으로 변경하지 않는다.
- 온전하지만 미발송: 별도 날짜의 실제 인계·수령 회신 후 완료.
- 장부: 온전함 유지 / 읽을 수 없음 유지 / 밀봉은 사흘 뒤 별도 개봉. 배 보수가 글씨를 복원하지 않는다.
- 윤서의 시정 책임은 새 모임 성공과 무관하게 계속된다.

## 구현 검증에 필요한 반례

1. 엔딩 384조합(6×4³)이 모든 중간편을 한 번씩 마치고 5편에 도달하는지, 6 방문순서가 나오는지.
2. 중간편 각 128 선택열(4×4×2×4)의 준비식과 실제 인계 일치.
3. 모두 틀리고 관계/인수를 택한 경우 길·신호·고정등 미완료가 남는다. R53 한 번으로 공개 B/C를 성공시킬 수 없어야 한다.
4. 역에서 답사는 했지만 최종 사람 안내를 고르고 동행 약속이 없으면 길 미완료.
5. 정연 참석 여부와 공개 신호 시험은 독립. 참석 보류여도 완주하고, 늦게 깜짝 독창하는 연출 없음.
6. 고정등/등 미사용은 publicReady여도 mobileReady가 아니다. C 축소 문구와 실제 실행 일치.
7. R51 현장 관찰·초기 동행·끝의 짧은 시범은 독립 검증/인수 무료 지급 아님.
8. 모로 비동행, 봉인 동행, 1편 배 손상/밀봉, 장부 읽기 불가를 모두 유지한 후속 플레이.
9. 전환·선택 직전/직후 저장 복원으로 이벤트 중복이나 물품 중복 지급이 없어야 한다.
10. 원고 P1~P6 대표 경로의 실제 입력·애셋 상태·NPC 위치·오디오·귀환을 브라우저로 별도 확인. 원고 열거 수치만으로 플레이 검증을 대신하지 않는다.
