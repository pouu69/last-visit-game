# T22 메시지 플레이 — 상태머신 실행 결과

> 생성 파일: `node scripts/demo-t22.mjs > artifacts/t22-demo.md`로 재생성한다. 직접 편집하지 않는다.

이 기록은 구현된 상태 전이 함수를 실행해 생성했다. 플레이어 행동과 판정 결과는 고정 예제이며 실제 참가자 대화나 OpenAI 호출 결과가 아니다. 음성·웹 화면·Three.js는 포함하지 않는다.

작성된 메시지 31개 · 판정 요청 효과 1회 · 실제 API 호출 0회 · 다음 장면 D21.

**윤서** · 마지막 전시예요. 이곳에 무엇이 남아 있었는지, 한 번은 더 보여 주고 싶었어요.

**팀** · 그래서 모로의 설명을 막으신 건가요?

**윤서** · 배를 옮겼다는 말만 들으면, 다들 모로가 훔쳤다고 생각할 테니까요.

**팀** · 끝까지 설명하게 두면 됐잖아요.

**윤서** · 그 애는 자기가 한 일을 순서대로 말해요. 그게 사람들에게 어떻게 들릴지는 생각하지 않고요.

**팀** · 관장님이 알고 있는 순서부터 듣죠. 배는 왜 진열장에 없나요?

**윤서** · 제가 옮기라고 한 건 아니에요.

**팀** · 관장님 말고 누군가 요청했을 수도 있겠네요.

**윤서** · 돌려달라는 연락은 받은 적 없어요. 모로가 혼자 움직인 거예요.

**팀** · 요청서에 관장님 수신 확인이 있는데요. 못 받았다는 말과 다르잖아요.

**윤서** · ……제 확인이 맞아요.

**윤서** · 받았어요. 내일 배를 띄우고 싶다고 적혀 있었죠. 읽고도 처리를 미뤘습니다.

**팀** · 나래 씨한테 기다려 달라고 하셨나요?

**윤서** · 아니요. 말하지 않았어요.

**윤서** · 저는 마지막 전시가 끝난 다음에 생각하려고 했어요.

**팀** · 아침 아홉 시에 필요하다고 적혀 있는데도요?

**윤서** · 그 문장을 안 읽은 게 아니에요. 읽고도, 오늘까지는 여기 있어 줬으면 했어요.

**팀** · 배 한 척이 그렇게 중요했나요?

**윤서** · 첫 전시품이니까요.

**윤서** · 여기가 아직 박물관 같아 보이려면, 적어도 저 자리는 채워져 있어야 한다고 생각했어요.

**팀** · 돌려준 자리라고 설명할 수도 있잖아요.

**윤서** · 손님들에게는 그렇게 말할 수 있었겠죠. 제가 그 빈자리를 보고 싶지 않았던 거예요.

**팀** · 그래서 모로가 옮겼다는 말도 끝까지 듣기 싫었던 건가요?

**윤서** · 그 말을 끝까지 들으면, 제가 미뤄 둔 일부터 설명해야 하니까요.

**팀** · 우리가 아직 확인해야 할 게 뭔가요?

**윤서** · 요청을 받은 기록, 원래 어떻게 돌려주기로 했는지 적힌 조항, 지금 손님들에게 보여 주는 안내요. 같이 봐야 해요.

**서술** · 요청 원문과 옛 반환 조항, 변경된 안내를 함께 대조한다. 윤서가 규약 변경과 요청 지연을 명시한 진술에 서명한다.

**윤서** · 돌려달라고 하면 돌려주기로 했어요. 그 문장을 제가 안내에서 뺐습니다. 이건 제 이름으로 남길게요.

**팀** · 요청을 읽고도 미뤘다는 내용도 넣어 주세요.

**윤서** · 네. 제가 확인했고, 처리하지 않았습니다.

**팀** · 이제 이 기록과 실제 규약을 대조해 보죠.

## 상태가 바뀐 지점

| 행동                         | 진행 상태  | 알려진 사실                                             | 보존 자료          | 장비 |
| ---------------------------- | ---------- | ------------------------------------------------------- | ------------------ | ---- |
| 관장이 요청 수신을 부인      | input      | 없음                                                    | request            | 없음 |
| 요청서와 질문 제출           | evaluating | 없음                                                    | request            | 없음 |
| 구두 인정 · 서명은 아직 없음 | input      | request_received, return_delayed                        | request            | 없음 |
| A 확정 · 규약 대조와 서명    | result     | request_received, return_clause_removed, return_delayed | request, statement | 없음 |
| D21 진입 정보 반환           | handoff    | request_received, return_clause_removed, return_delayed | request, statement | 없음 |

확정 사건 44개를 같은 원고·규칙 버전으로 재생해 최종 상태와 메시지 기록이 동일함을 확인했다. 재생 중 외부 요청 효과는 실행하지 않았다.
