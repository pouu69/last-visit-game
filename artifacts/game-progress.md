## 이전 지도판에서 이어받은 플레이

- 3장·21장면·84선택·11결정·6엔딩을 유지한다. 전체 대사를 사물별 조사에 배치하고 도장·운반 경로·인양 순서를 직접 구성한다.
- S22 핵심 사연은 원래 기록→요청과 인정→구조 준비 순서로 열린다. D21의 원본은 반환실의 잠긴 함에 남는다. P12는 시설 운반로 검증 후 관람 복도로 합류하는 목적을 설명한다.
- 비스듬한 일반 시점, 조사 클로즈업, 사용자 확대·회전·시선 높이·초기화. 주요 건축물·가구 외곽선, 문틀과 접지 그림자를 추가했다.

## 이전 지도판에서 확인한 범위

대표 경로 11결정으로 E3까지 실제 화면에서 완주했다. 바닥 클릭 이동·사물 접근·도장 조작·NPC 질문·반전 공개·인양 실패 후 복구·마지막 인계를 거쳤다. 마지막 상태는 배 손상·원본 보존·모로 충전 대기다. 이동 이벤트를 직접 호출해 공간을 건너뛰지 않았다.

390×844 모바일과 844×390 가로 화면에서 시점 패널, 버튼44px, 넘침, 두 손가락 확대를 확인했다. 확대·회전 중 캐릭터가 이동하지 않는다. 실제 휴대폰 확인과 참가자 재미·55분 진행 시간 측정은 남아 있다.

통합 검사81/81, 빌드27파일, ESLint 경고0, Prettier 확인 통과. NPC 입력 뒤 aria-disabled가 남던 문제는 브라우저에서 수정 전 실패·수정 후 실제 질문 성공을 확인했다. 새 이야기 시작 시 이전 엔딩 위치가 남던 문제도 수정 전 실패·수정 후 전시실 초기 배치를 확인했다. 같은 플레이의 조사 위치는 유지한다. 세부 근거는 [검증 결과](final-evidence.md)와 [브라우저 경로](map-browser-rehearsal.json)를 참고한다.

## 실행과 남은 범위

소스 서버는 http://127.0.0.1:5188 에서 실행 중이다. 새로고침한 뒤 팀의 ‘관람 시작’을 누르면 로비 도입부터 플레이한다. 저장한 이야기 이어보기는 기존 버전 기록을 보존한다. 배포본은 dist/에 생성했다. 외부 배포·푸시·병합은 하지 않았다.

자동 검증이 실제 참가자의 재미 검증을 대신하지는 않는다. 사람 리허설에서 이동량·읽기 시간·퍼즐 난이도를 조정할 수 있다.
