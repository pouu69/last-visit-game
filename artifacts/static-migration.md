# AI 제거와 정적 배포 전환

2026-10-28. AI 자유 대화·API 어댑터·키 설정·게임 HTTP API를 제거했다. 작성된 원고, 준비된 NPC 질문과 단서 추궁, 조사·퍼즐·결정·엔딩은 브라우저 상태머신에서 진행한다. 사용자가 승인한 정적 호스팅 전환 범위에 맞춘 변경이다.

## 실행과 저장

- `npm run build`로 만든 `dist/` 내용 전체를 정적 호스팅에 배치한다. 28개 정적 파일과 빌드 목록 1개이며 게임 서버 런타임은 필요하지 않다.
- `npm start`는 http://127.0.0.1:5188 의 로컬 파일 미리보기다. 소스 변경 뒤에는 다시 빌드한다. `/museum/` 같은 하위 경로도 지원한다.
- 게임 사건 기록은 localStorage에 자동 저장한다. 기록 내려받기·가져오기로 다른 기기에서 이어간다. 저장 실패 시 현재 화면에서 메모리 진행과 내보내기를 유지하고 경고한다.
- 이전 서버의 저장 JSON과 과거 AI 대사가 담긴 기록도 내부 사건 재생으로 복원한다. 새 AI 요청은 거절하며, 응답 대기 중인 옛 기록은 취소 사건을 추가해 재개한다.
- 원본 `.env`와 `data/sessions`는 읽거나 수정·삭제하지 않았다. 배포 산출물에 포함하지 않는다.

## storage-conflict

저장 실패 후 다른 탭의 최신 기록을 덮어쓰는 문제를 재현했다. A 탭의 쓰기가 실패한 뒤 B가 revision 3까지 저장하고 A의 쓰기가 복구되면, A의 다음 사건이 과거 진행인 revision 2로 디스크를 덮어썼다. 회귀 검사는 수정 전 실패했다.

저장 실패한 세션은 해당 화면에서 메모리 진행을 유지하며 자동 재쓰기를 하지 않도록 고쳤다. 경고와 파일 내보내기는 계속 제공한다. 파일을 새 세션으로 가져오면 브라우저 저장을 다시 시도할 수 있다. 같은 검사가 수정 후 통과했고 다른 탭의 revision 3과 A의 메모리 revision 2를 각각 보존했다.
