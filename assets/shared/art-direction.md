# 시리즈 공통 아트 디렉션

스타일 버전은 `series-art-v1`이다. 박물관·역·극장·수리소·강변의 사물과 공간은 다르게 만들고, 형태·재료·카메라 규칙을 공통으로 유지한다. 현재 기준 구현은 [공통 코어](../../public/assets/shared/core.mjs), [1편 제작 기록](../episodes/ep-01/brief.md), [실제 모델 정면 모음](../episodes/ep-01/review/catalogue-front.jpg)이다.

## 형태와 재료

- 큰 면과 읽기 쉬운 실루엣을 가진 저폴리 3D. 제조된 부품의 모서리는 작게 다듬는다.
- 나무·종이·천·도자기는 무광, 황동은 낮은 금속성, 유리와 물에만 제한된 투명도를 사용한다.
- 나뭇결·얼룩 같은 표면 노이즈보다 형태와 큰 색 면으로 구분한다.
- 카메라가 회전해도 실제 앞·뒤·옆·상부가 존재한다. 화면을 향해 돌리는 평면 소품으로 대체하지 않는다.
- 벽 부착물은 실제 벽 위치에, 물품은 받침면과 피벗에 맞춰 둔다. 닫힌 선체·막힌 문 구멍처럼 의미가 바뀌는 형상을 허용하지 않는다.

황동의 기준은 `metalness: 0.28`, `roughness: 0.6`이다. 다른 불투명 재료는 거칠기 약 0.88을 기본으로 한다. 인물 피부·머리·복장 색은 기존 인물의 승인된 모델을 기준으로 유지한다. 새 편의 강조색은 역할과 사용 위치를 브리프에 기록한 뒤 제한적으로 추가한다.

## 카메라와 빛

Y가 위, 기본 정면은 +Z이며 직교 카메라를 사용한다. 기준 시점은 yaw 35°·pitch 43°, 검수 범위는 yaw 0~360°·pitch 25~70°다. 광원은 월드 공간에 고정하고 화면을 따라 돌리지 않는다. 카메라 회전에 따라 보이는 명암은 자연스럽게 변한다.

정적 기본 재료와 약한 접지 음영을 우선 사용한다. 현재 기준은 후처리·그림자 맵 없이 DPR 최대 1.5, 30fps 목표다. 실제 프레임 시간은 새 편의 장면과 대상 기기에서 다시 측정한다. 1편의 방 크기 12×10 단위는 참고값이며, 새 편의 방과 소품은 실제 동선에 맞는 치수를 브리프에 명시한다.

텍스트는 CanvasTexture 또는 네이티브 UI로 작성한다. 이미지 생성 결과의 글자를 단서로 사용하지 않는다. 정규화 UV, 표지판 후면, 판 두께와 실제 읽을 수 있는 카메라 거리를 함께 확인한다.

## 공통 자산 변경

공통 코어의 팔레트·단위·기하·병합 규칙을 바꾸면 기존 편에도 영향이 간다. 변경 목적과 새 스타일/모델 버전을 기록하고 사용하는 편을 모두 다시 확인한다. 특정 편만의 차이는 그 편의 생성기와 옵션으로 구현한다.

공통 자산으로 옮기는 기준은 실제로 두 편 이상에서 같은 의미·형태로 사용하는지다. 현재 모로·플레이어·단말 등은 1편 배우 생성기에 있으며 재사용 후보다. 공통 폴더로 이동했다고 가정하거나, 등장 조건까지 자동으로 재사용하지 않는다.

![초기 스타일 참고 시트](references/museum-object-style-target.png)

이 이미지는 형태·색을 위한 컨셉 자료다. 이후 편의 완성 판단에는 실제 3D 모델과 게임 화면을 사용한다.
