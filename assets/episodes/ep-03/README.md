# 3편 — 마지막 곡의 빈자리

**상태: `planned-not-built` · 원고 기반 제작 후보**

근거 원고: [episode-03-theatre.md](../../../docs/series/episode-03-theatre.md). 아래 목록은 2026-10-28 원고에서 직접 등장한 대표 물품과 상태를 추출한 것이며, 아직 3D 모델·게임 장면·편별 manifest·카메라 검수 결과를 생성하지 않았다. 새 편을 제작할 때 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)와 [공통 스타일](../../shared/art-direction.md)을 먼저 확인한다.

**인물:** 소희와 정연의 새 전신 모델이 필요하다. 정연의 의자 운반·착석·손 신호를 계획한다. 원고의 참석 의향을 독창 공연 동작으로 바꾸지 않는다.

**공간:** 무대, 객석, 무대 뒤를 구분하고 의자 원 안으로 통로가 열리는 배치를 만든다. 뒤·옆 객석에서 손과 카드가 보이는지도 검수한다.

**인계 규칙:** 허용 배경음 / 새 공동 박자 / 시각 카드 / 음원 없는 손·말 신호 중 실제 결말 하나만 사용한다. 옛 독창은 어느 결말에서도 모임 공개용으로 전달되지 않는다. 녹음 사용 동의와 정연의 참석·출연 동의는 별도다. 화면의 파형·시각·악보는 게임 네이티브 정보로 만들고 이미지 생성 결과의 글자를 정답 자료로 사용하지 않는다. 실제 음원을 만들 때는 오디오 제작과 권리 기록을 별도로 진행한다.

## 제작 기록을 추가할 때

- 이 폴더는 원고 기반 요구사항과 제작 기록을 보관한다. 실제 런타임 모델의 예정 위치는 같은 편 번호의 `public/assets/episodes/ep-03/`다. 이 문서만으로 해당 코드 폴더나 실행 기능이 생기지 않는다.
- [공통 에셋 목록](../README.md)의 재사용 후보를 확인하고, 사용한 기존 모델의 원본 경로와 리비전을 편별 manifest에 기록한다. 현재 캐릭터·소품의 원본은 1편에 있으며, 실제로 여러 편에 필요한 것이 확인되면 공통 에셋으로 승격한다.
- `assets/templates/`의 브리프·manifest·검수 기록을 복사해 각 항목을 채운다. 미제작·미적용·미검수 상태를 승인 완료로 기록하지 않는다.
- 완료할 때는 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)의 기술·카메라·상태·실제 플레이 확인 결과를 이 폴더의 기록으로 연결한다.
