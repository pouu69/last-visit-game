# 3편 — 마지막 곡의 빈자리

**상태: `modelled` · 런타임 연결, 카메라·게임 최종 승인 대기**

근거 원고: [episode-03-theatre.md](../../../docs/series/episode-03-theatre.md). 아래 표는 원고 기반 요구사항이다. 현재 절차형 소품·인물 모델과 편별 manifest가 있으며 `public/series-world.mjs`에 연결했다. 표의 모든 상태·배치가 실제 화면에서 검증됐다는 뜻은 아니다. 제작·검수 시 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)와 [공통 스타일](../../shared/art-direction.md)을 먼저 확인한다.

**인물:** 소희와 정연은 `ep-02/actors.mjs`의 연작 인물 생성기를 사용한다. 정연의 의자 운반·착석·손 신호를 계획한다. 원고의 참석 의향을 독창 공연 동작으로 바꾸지 않는다.

**공간:** 무대, 객석, 무대 뒤를 구분하고 의자 원 안으로 통로가 열리는 배치를 만든다. 뒤·옆 객석에서 손과 카드가 보이는지도 검수한다.

**인계 규칙:** 허용 배경음 / 새 공동 박자 / 시각 카드 / 음원 없는 손·말 신호 중 실제 결말 하나만 사용한다. 옛 독창은 어느 결말에서도 모임 공개용으로 전달되지 않는다. 녹음 사용 동의와 정연의 참석·출연 동의는 별도다. 화면의 파형·시각·악보는 게임 네이티브 정보로 만들고 이미지 생성 결과의 글자를 정답 자료로 사용하지 않는다. 실제 음원을 만들 때는 오디오 제작과 권리 기록을 별도로 진행한다.

## 현재 구현과 검수

- 소품: `public/assets/episodes/ep-03/props.mjs`. 인물: `public/assets/episodes/ep-02/actors.mjs` 공용 연작 생성기. 플레이어·모로는 1편 생성기다.
- 진입: 박물관 엔딩 → `public/series-game.mjs`. 월드: `public/series-world.mjs`. 행동·투영: `public/series-action-plan.mjs`.
- 갤러리: `/asset-gallery.html?episode=3`. 저장: `return-path-series-v2:<museum sessionId>`.
- 원고·생성기 SHA-256은 [manifest](manifest.json)에 기록했다. 해시는 기록 당시 소스를 식별하며 후속 수정의 승인이나 테스트 통과를 뜻하지 않는다.
- 전체 카탈로그와 실제 장면의 사용 자산은 다르다. `modelled`를 유지하며 24방향 렌더·대표 배율 캡처와 부분 이미지 검토를 마쳤으며 장면 모션·실제 플레이 승인은 보류한다.
- 검증 범위와 남은 항목: [요구사항 감사](../../../artifacts/series-requirements-audit.md), [진행 기록](../../../artifacts/game-progress.md).

## 갤러리 렌더 검증 갱신

10항목·24방향 240뷰와 대표 모델 배율 9장을 생성했다. root가 전 항목 4방향 contact sheet 40뷰를 실제 검토했다. 전체 이미지 개별 검토·장면 모션·게임 승인은 별도이며 `modelled`를 유지한다. [검수 기록](review/review.md)에 렌더와 육안 검토 범위를 구분했다.
