정면·후면·측면·상부 contact sheet에서 전체 항목을 확인하고 대표 모델·상태를 확대해 살폈다. 912장의 모든 이미지를 각각 육안 판정한 것은 아니다. 확인 중 설명판의 들뜸과 글자 UV, 갤러리 황동 재료 차이, 종이배의 닫힌 선체 실루엣을 수정했다. 종이배는 열린 선체와 중앙 접힘을 가진 형상으로 다시 제작했다. 벽시계와 도구 걸이는 벽면에 맞춰 배치했다.

검수는 Headless Chromium의 WebGL에서 갤러리/방 1200×900, 실제 게임 1440×1000, DPR 1로 수행했다. 샘플의 최대 렌더 호출·삼각형 수는 [verification.json](verification.json)에 기록했다. GPU 프레임 시간과 모바일 실제 기기의 성능은 측정하지 않았다.

## 재현

Playwright가 설치된 Node 패키지 폴더를 마지막 인자에 준다. 런타임 게임 의존성은 추가하지 않았다.

```bash
node scripts/check-asset-visuals.mjs http://127.0.0.1:5188 /tmp/museum-visuals /path/to/node_modules
node scripts/check-asset-gameplay.mjs http://127.0.0.1:5188 /tmp/museum-gameplay /path/to/node_modules
```

첫 스크립트의 마지막에 `--rooms-only`를 주면 개별 모델 912뷰를 생략하고 방·상태·확대·모션 검수만 수행한다. 두 번째 스크립트는 별도 브라우저 컨텍스트에서 실제 UI와 저장 기록의 읽기 경로로 검수하므로 사용자의 기존 브라우저 진행 기록을 바꾸지 않는다.

## 시리즈 폴더 구조 적용 확인

공통 코어를 `public/assets/shared/core.mjs`, 1편 생성기를 `public/assets/episodes/ep-01/`로 옮겼다. 모델 소스 3개의 내용과 SHA-256은 이동 전과 동일하다. manifest와 검수 자료도 이 편 폴더에 모으고 참조를 갱신했다. 이동 후 빌드·전체 81개 테스트·갤러리 38항목 로드·게임 WebGL 초기화가 통과했으며 브라우저 오류는 없었다. 이 구조 변경 확인은 위에 기록된 모델 카메라 캡처를 새로 생성한 것으로 세지 않는다.
