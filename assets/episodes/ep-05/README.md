# 5편 — 지도 다음의 길

**상태: `modelled` · 런타임 연결, 카메라·게임 최종 승인 대기**

근거 원고: [episode-05-river.md](../../../docs/series/episode-05-river.md). 아래 표는 원고 기반 요구사항이다. 현재 절차형 소품·인물 모델과 편별 manifest가 있으며 `public/series-world.mjs`에 연결했다. 표의 모든 상태·배치가 실제 화면에서 검증됐다는 뜻은 아니다. 제작·검수 시 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)와 [공통 스타일](../../shared/art-direction.md)을 먼저 확인한다.

**인물:** 나래는 `ep-02/actors.mjs`의 연작 인물 생성기를 사용한다. 문정·소희·정연·이든은 앞선 편에서 제작한 모델을 재사용하되 실제 현장 역할·위치를 정한다. 모로는 동행을 선택한 경우에만 배치한다. 윤서의 마지막 연락은 메시지이며 현장 출연을 자동 추가하지 않는다.

**공간:** 역 뒤뜰 → 포장 보행로의 넓은 갈림점 → 평평한 위쪽 쉼터를 잇는다. 낮은 난간, 깊은 지붕 아래 그늘, 밝은 바깥 벤치, 계단 세 단 아래의 옛 계선장을 구분한다. 옛 계선장은 이번 단체 이동 경로에 포함하지 않는다.

**인계 규칙:** 2·3·4편을 모두 마친 뒤 시작한다. R53은 앞선 세 편에서 실제 얻은 결과를 각 하나씩 사용한다. 하나의 인물이 서로 다른 장소의 인솔과 쉼터 안내를 동시에 수행하지 않게 배치한다. 종료 후 표지는 문정, 재생 장비·카드는 소희, 조명은 이든 등 원고의 담당자에게 돌아간다. 길에 전시품이 영구히 남는 장면으로 끝내지 않는다.

## 현재 구현과 검수

- 소품: `public/assets/episodes/ep-05/props.mjs`. 인물: `public/assets/episodes/ep-02/actors.mjs` 공용 연작 생성기. 플레이어·모로는 1편 생성기다.
- 진입: 박물관 엔딩 → `public/series-game.mjs`. 월드: `public/series-world.mjs`. 행동·투영: `public/series-action-plan.mjs`.
- 갤러리: `/asset-gallery.html?episode=5`. 저장: `return-path-series-v2:<museum sessionId>`.
- 원고·생성기 SHA-256은 [manifest](manifest.json)에 기록했다. 해시는 기록 당시 소스를 식별하며 후속 수정의 승인이나 테스트 통과를 뜻하지 않는다.
- 전체 카탈로그와 실제 장면의 사용 자산은 다르다. `modelled`를 유지하며 24방향 렌더·대표 배율 캡처와 부분 이미지 검토를 마쳤으며 장면 모션·실제 플레이 승인은 보류한다.
- 검증 범위와 남은 항목: [요구사항 감사](../../../artifacts/series-requirements-audit.md), [진행 기록](../../../artifacts/game-progress.md).

13항목·24방향 312뷰와 대표 모델 배율 9장을 생성했다. root가 전 항목 4방향 contact sheet 52뷰를 실제 검토했다. 전체 이미지 개별 검토·장면 모션·게임 승인은 별도이며 `modelled`를 유지한다. [검수 기록](review/review.md)에 렌더와 육안 검토 범위를 구분했다.
