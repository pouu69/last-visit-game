# 5편 — 지도 다음의 길

**상태: `planned-not-built` · 원고 기반 제작 후보**

근거 원고: [episode-05-river.md](../../../docs/series/episode-05-river.md). 아래 목록은 2026-10-28 원고에서 직접 등장한 대표 물품과 상태를 추출한 것이며, 아직 3D 모델·게임 장면·편별 manifest·카메라 검수 결과를 생성하지 않았다. 새 편을 제작할 때 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)와 [공통 스타일](../../shared/art-direction.md)을 먼저 확인한다.

**인물:** 나래의 새 전신 모델이 필요하다. 문정·소희·정연·이든은 앞선 편에서 제작한 모델을 재사용하되 실제 현장 역할·위치를 정한다. 모로는 동행을 선택한 경우에만 배치한다. 윤서의 마지막 연락은 메시지이며 현장 출연을 자동 추가하지 않는다.

**공간:** 역 뒤뜰 → 포장 보행로의 넓은 갈림점 → 평평한 위쪽 쉼터를 잇는다. 낮은 난간, 깊은 지붕 아래 그늘, 밝은 바깥 벤치, 계단 세 단 아래의 옛 계선장을 구분한다. 옛 계선장은 이번 단체 이동 경로에 포함하지 않는다.

**인계 규칙:** 2·3·4편을 모두 마친 뒤 시작한다. R53은 앞선 세 편에서 실제 얻은 결과를 각 하나씩 사용한다. 하나의 인물이 서로 다른 장소의 인솔과 쉼터 안내를 동시에 수행하지 않게 배치한다. 종료 후 표지는 문정, 재생 장비·카드는 소희, 조명은 이든 등 원고의 담당자에게 돌아간다. 길에 전시품이 영구히 남는 장면으로 끝내지 않는다.

## 제작 기록을 추가할 때

- 이 폴더는 원고 기반 요구사항과 제작 기록을 보관한다. 실제 런타임 모델의 예정 위치는 같은 편 번호의 `public/assets/episodes/ep-05/`다. 이 문서만으로 해당 코드 폴더나 실행 기능이 생기지 않는다.
- [공통 에셋 목록](../README.md)의 재사용 후보를 확인하고, 사용한 기존 모델의 원본 경로와 리비전을 편별 manifest에 기록한다. 현재 캐릭터·소품의 원본은 1편에 있으며, 실제로 여러 편에 필요한 것이 확인되면 공통 에셋으로 승격한다.
- `assets/templates/`의 브리프·manifest·검수 기록을 복사해 각 항목을 채운다. 미제작·미적용·미검수 상태를 승인 완료로 기록하지 않는다.
- 완료할 때는 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)의 기술·카메라·상태·실제 플레이 확인 결과를 이 폴더의 기록으로 연결한다.
