# 5편 연작의 에셋 요구사항

이 문서는 [《돌아가는 길》 연작 원고](../../docs/series/README.md)에서 추출한 편별 제작 출발점이다. 편의 제목은 원고의 제목을 따른다. `episode-01-bridge.md`는 기존 박물관 전체와 연결 원고이며, 별도의 다리 배경 에피소드가 아니다.

2026-10-28 기준 1편 박물관의 실제 모델 36종과 상태 변형 2개가 게임에 적용되어 있다. 2~5편은 원고만 있으며, 아래 새 공간·인물·물품은 모두 **`planned-not-built`**다. 목록에 적힌 것만으로 모델 생성·게임 연결·카메라 검수가 끝난 것은 아니다. 1편의 연작 연결 원고도 기존 실행 게임에 삽입되지 않았다.

공통 시각 기준은 [공통 아트 디렉션](../shared/art-direction.md), 현재 생성 함수·피벗·충돌·상태 연결 방법은 [오브젝트 제작 가이드](../OBJECT_ASSET_GUIDE.md)를 따른다. 아래 목록은 대표 요구사항이며, 실제 제작 전 각 장면의 조사·퍼즐·결말에 필요한 전체 항목으로 확장한다.

현재 소품·배우의 원본은 `public/assets/episodes/ep-01/`이다. 여러 편에서 실제 재사용할 필요를 확인한 모델만 공통 폴더로 승격한다. 같은 생성기를 쓸 수 있다는 것과 이야기 속 같은 물건이라는 것은 다르다. 다른 장소의 벤치·상자·종이는 별도 개체로 관리한다. 신규 인물은 공통 비율과 리깅 구조를 참고하되, 기존 인물의 이름만 바꾼 복제본으로 처리하지 않는다. 1편의 나래는 단말 속 초상이며, 5편의 현장 참석에는 별도의 전신 모델과 동작이 필요하다.

## 1편 — 폐관 후의 박물관

[1편 manifest](ep-01/manifest.json)를 기준 목록으로 사용한다. 빈 진열장, 종이배, 원본 장부, 보관함, 정비·인양 장치, 기록실 가구, 윤서·모로·관람객, 단말과 대차가 포함된다. 새 연작 연결 원고를 나중에 게임화할 때는 원고에 실제로 등장하는 메시지·회신·안내지에 필요한 표현만 추가한다.

- **공간:** 기존 박물관의 9개 방과 연결 통로.
- **인물:** 윤서·모로·플레이어의 기존 모델을 사용한다. 나래의 원격 메시지와 현장 등장 여부를 구분한다.
- **상태:** 배의 온전함·손상·밀봉·반환, 장부의 보존·번짐·밀봉, 모로의 전원·운반 상태를 유지한다.
- **인계:** E1에서 강에 띄운 원래 배를 후속편 소지품으로 다시 만들지 않는다. 번진 장부는 배 보수와 함께 자동 복원되지 않는다. 후속 개봉·보수·반환이 서술된 경우에만 그 시점 이후 상태를 바꾼다.

근거: 연결 원고의 「모로의 동행」, 「시간과 기존 상태 처리」, 「준비 기간에 도착한 회신」.

## 2~5편의 제작 후보

각 폴더의 README는 원고 기반 요구사항이다. 실제 모델 생성 코드·manifest·검수 이미지는 제작 이후에 추가한다.

- [2편: 종착역의 반대편](ep-02/README.md) — 표지판의 앞뒤 방향과 받침, 반송 상자, 두 방향 약도.
- [3편: 마지막 곡의 빈자리](ep-03/README.md) — 의자·마이크·트랙 대조 화면·신호 카드, 공개/개인 청취 구분.
- [4편: 수리하지 않는 것](ep-04/README.md) — 안내등·고정쇠·차광판·고정/운반 조립·손표지.
- [5편: 지도 다음의 길](ep-05/README.md) — 새 종이·물대야·반원 의자·쉼터와 앞선 편에서 실제 인계한 장비.

## 편 사이 상태를 검수하는 기준

1. **방문 순서:** 2·3·4편의 여섯 방문 순서를 고려한다. 아직 가지 않은 편의 소품·사람·조사 결과를 먼저 배치하지 않는다.
2. **선택 결과:** 편별 결말 하나만 인계한다. 준비 선택과 최종 인계 물품을 혼동하지 않는다. 예를 들어 옛 판의 받침을 점검했다고 새 이중 표지 받침을 얻은 것은 아니다.
3. **소유와 위치:** 생성기 재사용, 같은 물건의 이동, 다른 물건의 신규 생성을 별도 기록한다. 보관·소지·설치·회수 위치에 같은 물품이 동시에 중복 등장하지 않게 한다.
4. **모로:** 동행·전원·접속부 봉인을 각각 기록한다. 비동행이면 2~5편에 몸체·대사·가상의 원격 모로를 추가하지 않는다. 과거 방전이 다음 날 충전됐어도 봉인이 자동 해제되지는 않는다.
5. **종이배와 장부:** 과거 손상·번짐과 후속 개봉·보수·인계를 구분한다. 새로 접은 배에 기존 원본의 식별자를 재사용하지 않는다.
6. **소리와 조명:** 옛 독창의 비공개 상태, 사람의 시작·정지 신호, 지속 조명을 구분한다. 없는 음원·점멸 기능·전원을 새로 만들어 주지 않는다.
7. **카메라:** 표지의 앞/뒤 화살표, 약도의 펼친 면, 카드·손 신호의 가림, 차광판과 앉은 사람의 눈높이를 실제 플레이 시점에서 확인한다. 단일 예쁜 렌더로 완료 처리하지 않는다.

새 편 원고가 바뀌면 이 문서와 해당 편 manifest의 근거 장면을 함께 갱신한다. 아직 정하지 않은 치수·정확한 공간 수·의상·새 ID·애니메이션 프레임은 이 목록에서 확정된 것으로 취급하지 않는다.
