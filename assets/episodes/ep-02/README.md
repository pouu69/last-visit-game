# 2편 — 종착역의 반대편

**상태: `planned-not-built` · 원고 기반 제작 후보**

근거 원고: [episode-02-station.md](../../../docs/series/episode-02-station.md). 아래 목록은 2026-10-28 원고에서 직접 등장한 대표 물품과 상태를 추출한 것이며, 아직 3D 모델·게임 장면·편별 manifest·카메라 검수 결과를 생성하지 않았다. 새 편을 제작할 때 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)와 [공통 스타일](../../shared/art-direction.md)을 먼저 확인한다.

**인물:** 문정의 새 전신 모델이 필요하다. 유모차를 미는 이웃은 실제 현장 관찰에 등장하므로, 장면화할 때 사람·유모차 표현을 함께 계획한다. 플레이어와 동행한 경우의 모로는 공통 모델을 사용한다.

**공간:** 닫힌 매표소, 열린 화물실, 정문과 계단, 뒤뜰, 선로와 분리된 완만한 포장 보행로, 두 방향의 갈림점을 구분한다. 이 목록은 원고의 장소 단위이며 최종 방 수나 맵 치수가 아니다.

**인계 규칙:** 옛 표지 보관 / 새 이동식 이중 표지 / 개인 약도 / 점검한 옛 이동 표지 중 실제 선택한 방식만 다음 편에 나타난다. 새 이중 표지는 문구 확인을 마친 이동식 행사 물품이며 영구 설치물처럼 남기지 않는다. 선로와 계단을 유효 이동 경로로 표시하지 않는다.

## 제작 기록을 추가할 때

- 이 폴더는 원고 기반 요구사항과 제작 기록을 보관한다. 실제 런타임 모델의 예정 위치는 같은 편 번호의 `public/assets/episodes/ep-02/`다. 이 문서만으로 해당 코드 폴더나 실행 기능이 생기지 않는다.
- [공통 에셋 목록](../README.md)의 재사용 후보를 확인하고, 사용한 기존 모델의 원본 경로와 리비전을 편별 manifest에 기록한다. 현재 캐릭터·소품의 원본은 1편에 있으며, 실제로 여러 편에 필요한 것이 확인되면 공통 에셋으로 승격한다.
- `assets/templates/`의 브리프·manifest·검수 기록을 복사해 각 항목을 채운다. 미제작·미적용·미검수 상태를 승인 완료로 기록하지 않는다.
- 완료할 때는 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)의 기술·카메라·상태·실제 플레이 확인 결과를 이 폴더의 기록으로 연결한다.
