# 2편 — 종착역의 반대편

**상태: `modelled` · 런타임 연결, 카메라·게임 최종 승인 대기**

근거 원고: [episode-02-station.md](../../../docs/series/episode-02-station.md). 아래 표는 원고 기반 요구사항이다. 현재 절차형 소품·인물 모델과 편별 manifest가 있으며 `public/series-world.mjs`에 연결했다. 표의 모든 상태·배치가 실제 화면에서 검증됐다는 뜻은 아니다. 제작·검수 시 [연작 제작 절차](../../SERIES_ASSET_WORKFLOW.md)와 [공통 스타일](../../shared/art-direction.md)을 먼저 확인한다.

**인물:** 문정은 `ep-02/actors.mjs`에 구현했다. 유모차를 미는 이웃은 실제 현장 관찰에 등장하므로, 장면화할 때 사람·유모차 표현을 함께 계획한다. 플레이어와 동행한 경우의 모로는 공통 모델을 사용한다.

**공간:** 닫힌 매표소, 열린 화물실, 정문과 계단, 뒤뜰, 선로와 분리된 완만한 포장 보행로, 두 방향의 갈림점을 구분한다. 이 목록은 원고의 장소 단위이며 최종 방 수나 맵 치수가 아니다.

| 대표 제작 대상 | 공통 자산 활용 | 편 전용 형태·상태와 근거 |

## 현재 구현과 검수

- 소품: `public/assets/episodes/ep-02/props.mjs`. 인물: `public/assets/episodes/ep-02/actors.mjs` 공용 연작 생성기. 플레이어·모로는 1편 생성기다.
- 진입: 박물관 엔딩 → `public/series-game.mjs`. 월드: `public/series-world.mjs`. 행동·투영: `public/series-action-plan.mjs`.
- 갤러리: `/asset-gallery.html?episode=2`. 저장: `return-path-series-v2:<museum sessionId>`.
- 원고·생성기 SHA-256은 [manifest](manifest.json)에 기록했다. 해시는 기록 당시 소스를 식별하며 후속 수정의 승인이나 테스트 통과를 뜻하지 않는다.
- 전체 카탈로그와 실제 장면의 사용 자산은 다르다. `modelled`를 유지하며 24방향 렌더·대표 배율 캡처와 부분 이미지 검토를 마쳤으며 장면 모션·실제 플레이 승인은 보류한다.
- 검증 범위와 남은 항목: [요구사항 감사](../../../artifacts/series-requirements-audit.md), [진행 기록](../../../artifacts/game-progress.md).

11항목·24방향 264뷰와 대표 모델 배율 9장을 생성했다. root가 전 항목 4방향 contact sheet 44뷰를 실제 검토했다. 전체 이미지 개별 검토·장면 모션·게임 승인은 별도이며 `modelled`를 유지한다. [검수 기록](review/review.md)에 렌더와 육안 검토 범위를 구분했다.
