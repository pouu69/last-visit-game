# 1차 초안 점검

1차 초안은 원고와 엔진을 먼저 작성했지만, 이야기의 인과관계와 분기의 목적을 검토할 기준이 부족했다. 아래는 문서와 코드를 읽어 확인한 사항이며 실행 테스트 결과가 아니다.

| 문제 | 근거 | 2차 설계에서 해결할 방식 |
| --- | --- | --- |
| 실제 이동 경로가 약하다 | 엔진의 `choose`가 모든 선택에서 `step + 1`로 진행한다. 첫 조사 뒤 대부분 같은 장면 순서다. | 장면 ID와 이동 대상을 명시하고, 서로 다른 조사·위기·결말 준비 장면을 둔다. |
| 마지막 메뉴에 엔딩이 집중된다 | `ending`은 12번째 A~D와 배/주소·원본/동의로 결과를 고른다. | 마지막 전에 실행 방향을 정하고, 방향별 마지막 사건을 겪은 뒤 누적 상태로 결말이 나오게 한다. |
| 물건의 위치가 일관되지 않는다 | 4·6번째 장면에서 원본을 이미 챙겼는데 8번째에는 배와 함께 침수 함에서 구한다. | 원본은 구조 전까지 한 곳에 고정한다. 먼저 얻는 것은 사본·확인서·주소·동의로 구분한다. |
| 분실과 복원의 규칙이 불분명하다 | 여러 장면에서 동일한 `original` 플래그가 추가되며 같은 원본인지 다른 자료인지 모호하다. | 어떤 단서가 무엇을 증명하는지 구분하고, 훼손된 원본을 새 사본으로 되살리지 않는다. |
| 위험을 쉽게 제거할 수 있어 보인다 | 자동 폐기를 관장이 마지막에 취소할 수 있다면 먼저 취소하지 않은 이유가 약하다. | 위험을 물리적 침수와 고장으로 바꾸고, 정지 버튼·여러 사람의 손으로 바로 해결되지 않는 이유를 공간에 명시한다. |
| 퍼즐 해설 일부가 답과 맞지 않는다 | 미션1의 C는 종과 물결 간격 규칙을 만족하지만 공통 해설은 C도 간격이 틀렸다고 쓴다. | 정답뿐 아니라 각 오답이 어기는 제약까지 독립적으로 검토한다. |
| 중후반 질문이 같은 가치판단을 반복한다 | 동의·반환·전시·기록을 여러 번 고르지만 실제 사건 변화가 적다. | 조사, 추리, 자원 선택, 구조, 합의, 실행을 나누고 반복 질문을 줄인다. |
| 장비 효과가 미리 충분히 드러나지 않는다 | 마지막 구출 단계에서 자동으로 우선순위 장비를 사용하는 D가 등장한다. | 한 번 선택한 장비의 사용처를 앞서 예고하고, 소비 여부와 대가를 선택 전에 보여준다. |

보존: 기존 초안 코드는 삭제하거나 새 설계에 맞춰 고치지 않는다. 설계 승인 이후 필요한 부분만 다시 구현한다.
