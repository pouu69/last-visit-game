# 게임 장면 레퍼런스와 적용 기준

《폐관 후의 박물관》은 장면 속 인물·단서·행동 결과를 보면서 대화를 읽는 게임으로 연출한다. 아래 세 게임에서 확인한 구도와 인물 표현을 현재 원고·상태 규칙에 맞춰 적용한다.

## 확인 범위

2026-10-27 공식 개발사·퍼블리셔 페이지의 설명을 읽고, 각 페이지가 제공하는 아래 스크린샷을 직접 열어 시각적으로 확인했다. 게임을 직접 플레이하거나 영상을 재생한 검토는 아니다. 따라서 애니메이션 속도·카메라 전환 시간·조작 감각은 관찰한 사실로 주장하지 않는다. 공식 페이지에서의 화면 관찰과 우리 게임에 제안하는 연출을 구분한다.

| 게임               | 공식 페이지                                                                | 직접 확인한 이미지                                                                                             |
| ------------------ | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| The Last Campfire  | [Hello Games 공식 게임 사이트](https://thelastcampfiregame.com/)           | [숲 속 통나무와 Ember 장면](https://thelastcampfiregame.com/images/features/homepage-features-10-1280x720.jpg) |
| OXENFREE           | [Night School Studio 공식 페이지](https://nightschoolstudio.com/oxenfree/) | [해변 모닥불과 세 대화 선택지](https://nightschoolstudio.com/wp-content/uploads/2020/01/oxenfree_screen_2.jpg) |
| Night in the Woods | [Finji 공식 퍼블리셔 페이지](https://finji.co/games/nightinthewoods/)      | [숲 속 인물과 큰 대화 말풍선](https://finji.co/assets/images/nitwscreenshot1.jpg)                              |

Night in the Woods의 별도 게임 도메인은 이 환경에서 연결되지 않아 확인했다고 기록하지 않는다. Finji 페이지는 HTTP 200으로 확인했고 개발사 Infinite Fall, 게임 소개, 공식 스크린샷이 함께 제공된다.

## 화면에서 확인한 것

### The Last Campfire — 하나의 장면에서 무엇을 볼지 명확하다

직접 본 이미지의 배경은 어두운 청록색 숲이다. 중앙의 작은 인물, 쓰러진 통나무, 밝은 꽃이 빛과 명도 차이로 분리되어 있다. 전경의 돌과 풀, 중경의 행동 대상, 뒤쪽 나무가 서로 다른 깊이로 읽힌다. 각 물체는 단순한 면과 큰 덩어리로 구성되지만 인물의 몸 방향과 시선이 주변 대상과 연결된다.

공식 소개는 이를 목적과 귀로를 찾는 작은 Ember의 퍼즐 모험으로 설명한다. 이 이미지 한 장으로 퍼즐의 조작 방식이나 대화 시스템까지 확인한 것은 아니다.

박물관에 적용할 원칙은 **장면마다 가장 중요한 인물 한 명과 소품 한두 개를 먼저 읽히게 하는 것**이다. S01은 빈 진열장, T21은 모로와 이송 화면, T22는 윤서와 열쇠·기록, R31/R32는 두 함과 격벽이 초점이다. 숲의 풀·동물·꽃을 박물관에 가져오는 식으로 적용하지 않는다.

### OXENFREE — 선택과 대화가 인물이 서 있는 공간에 붙어 있다

해변 스크린샷은 넓은 밤하늘과 수평의 바다를 배경으로, 화면 아래에 여러 인물과 따뜻한 모닥불을 배치한다. 세 가지 짧은 대화 선택지가 인물 가까이에 말풍선으로 붙어 있어 누가 있는 장면에서 응답을 고르는지 보인다. 인물이 작아도 색과 위치가 다르고, 모닥불의 빛이 대화가 일어나는 영역을 묶는다.

공식 페이지는 결정에 따라 이야기와 관계가 바뀌는 대화 시스템을 명시한다. 스크린샷만으로 응답 제한 시간이나 이동 중 대화 처리까지 확인한 것은 아니다.

박물관에서는 **현재 화자와 장면 속 인물이 연결되도록** 적용한다. 긴 원고는 하단 대화창에서 읽고, 화자 이름·인물의 짧은 반응·카메라 초점이 함께 바뀐다. 네 선택과 단서 추궁은 그 장면 안에서 열며, 읽는 시간이 자원이나 수위를 바꾸지 않는 기존 규칙을 유지한다.

### Night in the Woods — 간결한 인물도 실루엣과 시선으로 구별된다

숲 스크린샷에는 머리 크기, 귀·안경·옷의 형태가 다른 인물들이 모여 있다. 큰 눈의 방향과 몸의 방향만으로도 서로에게 주의를 두는 모습이 보인다. 검은 전경 지형, 푸른 중경 나무, 뒤쪽 인물의 실루엣이 겹치며 깊이를 만든다. 노란 글씨의 큰 말풍선은 꼬리가 화자 쪽으로 향한다.

Finji는 이 게임을 고향으로 돌아온 Mae와 달라진 친구들, 마을의 이상한 일을 다루는 narrative adventure로 소개한다. 이 검토에서 포즈 사이의 애니메이션이나 걷기 주기는 확인하지 않았다.

박물관에서는 **모로·윤서·나래를 형태와 자세로 구별하는 원칙**을 적용한다. 모로는 낮은 몸체와 바퀴·렌즈·집게, 윤서는 길게 내려오는 옷과 열쇠를 쥔 손, 나래는 연락 단말 안의 얼굴로 읽힌다. 나래가 박물관 현장에 와 있는 것처럼 배치하지 않는다.

## 현재 구현에 맞춘 구체 변경안 5개

현재 `public/museum-scene.mjs`에는 정사영 카메라, 모로·윤서·연락 단말, 화자에 따른 포즈, 배·장부·모로 상태 표현이 있다. 이 작업을 재작성하기보다 아래 기준으로 장면을 조정한다.

### 1. 장면의 핵심 대상에 맞춰 카메라와 배치를 구분한다

건물 전체가 보이는 같은 구도를 반복하기보다 대면·조사·구조가 서로 다른 화면으로 읽히게 한다. 모델을 바꿀 필요 없이 기존 공간의 카메라 목표점과 인물 위치부터 조정할 수 있다.

| 장면            | 화면의 중심                        | 주변에 남길 것                     | 공개 순서                                                                       |
| --------------- | ---------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------- |
| S01             | 빈 진열장과 윤서                   | 복도 쪽 모로, 끊어진 물자국        | 배가 진열장에 다시 생기지 않는다.                                               |
| I01·T21         | 모로와 가슴의 이송 화면            | 정비 통로, 젖은 접수표             | 접수표가 배 조각이 아님은 해당 대사를 읽은 뒤 강조한다.                         |
| I02·D21         | 기록 책상과 문서 두 장             | 윤서 또는 모로의 몸 일부           | 규약 원문과 현재 안내의 비교를 보이되 미확보 문서를 소지품으로 표시하지 않는다. |
| I03·D22         | 바닥의 물길과 밸브·도면            | 마른 안전 통로                     | `map`과 `maintenance`를 서로 다른 시각 상태로 둔다.                             |
| I04·T22         | 윤서의 얼굴·손과 열쇠              | 빈 진열장, 질문 대상 기록          | `request_received`가 있으면 수신 부인 연기를 다시 하지 않는다.                  |
| S22·P21·R31/R32 | 격벽 너머 서로 떨어진 두 함        | 레일·전원 연결부, 안전한 인물 위치 | P21은 순서 검증이므로 함이 실제 올라오지 않는다.                                |
| S31             | 연락 단말 속 나래와 현재 구조 결과 | 배·장부·모로의 실제 상태           | 나래는 원격 연락 중이며 배는 아직 자동 발송되지 않는다.                         |
| F33·E5          | 모로와 운반 수레, 출구 방향        | 인계 기록과 담당자                 | 잠든 상태는 운반만으로 바뀌지 않는다.                                           |

모바일에서도 화자의 얼굴과 주요 소품이 하단 대화창 뒤에 가려지지 않도록 같은 장면을 별도 화면 비율로 구성한다. 전체 건물을 맞춰 넣느라 인물과 단서가 알아보기 어려워지는 구도는 피한다.

### 2. 인물마다 이야기에서 의미 있는 자세를 둔다

모로는 설명할 때 화면·집게를 질문 대상으로 돌리고, `moro=asleep`이면 렌즈·안테나의 불과 몸의 반응을 모두 멈춘다. F33-A에서는 작동 여부에 맞춰 수레 위 자세를 유지한다. 윤서는 열쇠를 쥔 손과 기록을 바라보는 시선으로 대면을 표현하고, 요청 수신을 인정한 메시지에서는 손을 낮추거나 기록을 향하도록 한다. 나래는 S31 이후 연락 화면 안에서만 표시한다.

모든 대사에 같은 고개 끄덕임을 반복하지 않는다. 화자 변경, 단서 제시, 실제 인정처럼 의미가 있는 순간에만 짧은 반응을 사용한다. 인물의 반응이 끝날 때까지 다음 문장을 막지는 않는다.

### 3. 말하는 사람과 제시한 단서를 화면에서 연결한다

하단 대화창의 현재 화자와 장면 속 인물에 같은 강조색을 사용한다. 화자의 얼굴이나 화면 쪽에 작은 이름 표식을 두거나, 다른 인물보다 대비를 조금 높여 대사의 출처를 바로 알 수 있게 한다. 긴 대사를 공간 위에 중복으로 떠다니게 만들 필요는 없다.

T22에서 보유한 `request`를 선택하면 서류의 수신 확인 위치에 표시를 두고, 추궁 결과가 실제 공개된 뒤 윤서의 반응을 바꾼다. 선택한 서류가 있다는 사실만으로 자백 포즈를 미리 재생하지 않는다. 모로·윤서·나래의 생성 대사도 동일한 화자 규칙으로 표시한다.

### 4. 선택 결과를 색뿐 아니라 물체의 형태와 위치로 보여준다

| 상태                        | 읽히는 형태                             | 생기면 안 되는 오해                              |
| --------------------------- | --------------------------------------- | ------------------------------------------------ |
| `boat=intact`               | 접힌 선이 남은 온전한 배                | 온전하다고 곧 발송된 것은 아니다.                |
| `boat=damaged`              | 한쪽 가장자리의 분명한 찢김             | 보수 도구만 소지해도 자동 수리되지 않는다.       |
| `boat=sealed`               | 배 대신 닫힌 함과 봉인                  | 밀봉은 회수·발송 완료가 아니다.                  |
| `record=unreadable`         | 번진 면이 있는 장부                     | 배를 수리해도 장부 글씨는 돌아오지 않는다.       |
| `moro=asleep`               | 꺼진 렌즈, 멈춘 자세, 필요 시 운반 수레 | 임의의 대기 시간으로 다시 깨어나지 않는다.       |
| `battery=false`로 실제 소모 | 사용한 전원 연결부 또는 빈 보관 위치    | 다른 장소에 두 번째 배터리가 다시 생기지 않는다. |

변화는 엔진의 확정 결과에서만 시작하고 다음 장면에서도 유지한다. 물결 같은 환경 움직임이 있더라도 시간이 흐를수록 구조 조건이 악화되는 표현은 쓰지 않는다.

### 5. 밝기와 깊이로 이야기의 초점을 만든다

The Last Campfire에서 본 밝은 대상과 어두운 배경의 관계, 두 2D 게임에서 본 전경·인물·후경의 층을 박물관의 재료에 적용한다. 뒤쪽 아치창·벽은 차가운 어둠, 현재 조사 대상은 따뜻한 책상등·전시등, 전경 일부는 낮은 대비의 난간이나 가구로 구성한다. 소품마다 똑같이 밝은 상태보다 지금 읽는 사건의 중심이 먼저 보이게 한다.

S01은 빈 받침대의 빛, T22는 얼굴과 손·서류, R31/R32는 두 함과 격벽, E5는 출구 방향과 수레가 먼저 읽혀야 한다. 화면 전체에 빛 번짐을 추가하는 것보다 초점 외의 배경을 덜 밝히고 카메라를 조정하는 작업을 먼저 한다. 감소된 모션 환경에서는 이 구도와 상태를 정적으로 즉시 보여준다.

## 적용과 검토의 범위

레퍼런스 이미지·캐릭터·음악을 게임 자산으로 복사하지 않는다. 현재의 박물관 원고, 독립적인 인물 디자인, 기존 Three.js 소품을 사용한다. 새로운 자산 팩을 도입하는 것은 위 연출을 구현하기 위한 선행 조건이 아니다.

최종 화면 검토는 S01, T22의 인정 전후, R32-C의 구조 결과, S31 원격 연락, E5 잠든 모로의 운반을 대표 장면으로 삼는다. 이 장면에서 화자·단서·결과 상태가 읽히는지 데스크톱과 모바일로 확인한다. 이 문서는 레퍼런스 조사와 적용 제안이며, 해당 화면 검토까지 완료했다는 기록은 아니다.
