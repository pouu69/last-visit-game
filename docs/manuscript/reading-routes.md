# 경로별 읽기 검토

각 경로를 처음부터 끝까지 이어 읽으며, 먼저 알지 못한 사실을 아는 척하는 대사와 실제로 얻지 않은 물건을 쓰는 장면을 찾는다. 아래 세 경로와 조건부 엔딩을 원고에서 이어 읽었다.

## 1. 배를 돌려보내는 경로

`S01-A → I01-B → P12-B → S12-A → T21-D → D22-A → S22-B → P21-B → R31-D → S31-A → F31-A → E1`

| 확인할 장면 | 읽을 때 기대하는 사실 |
| --- | --- |
| I01-B, P12-B | 배터리와 도면을 하나씩 확보한다. 이미 보유한 물건을 두 개로 늘리지 않는다. |
| T21-D, D22-A | 도면이 있으므로 수동 배수선 점검·개방을 마칠 수 있다. |
| S22-B | 처음 조사한 것이 장비여도 기증자의 진짜 뜻과 윤서의 각색을 알게 된다. 서명 진술을 남긴다. |
| P21-B, R31-D | P21은 예약 검증, 인양은 R31에서 한 번. 외부 구조에 배터리를 사용한다. |
| S31, F31-A, E1 | 배·원본은 온전하며 모로는 작동. 배터리는 남아 있지 않다. 나래 확인 후 실제 배 반환으로 이어진다. |

## 2. 규약 변경을 밝혀내는 경로

`S01-B → I02-A → P11-C → S12-D → T22-C → D22-D → S22-B → P21-C → R32-B → S31-B → F32-B → E3`

| 확인할 장면 | 읽을 때 기대하는 사실 |
| --- | --- |
| I02-A, P11-C | 옛 규약 사본을 보유한다. 미션 오답이므로 추가 도면은 없다. |
| T22-C, D22-D | 수신 확인을 직접 확보하지 않은 경로도 대화 가능. 배터리와 보수 도구를 확보한다. |
| S22-B, P21-C | 핵심 진실과 서명을 확보한다. 미션2 실패로 정상 구조가 아닌 R32로 간다. |
| R32-B | 원본은 온전, 배는 손상, 모로는 방전. 이후 모로에게 작동 중인 것처럼 말시키지 않는다. |
| F32-B | 남은 배터리를 실제 소모해 모로를 깨운 뒤 로그를 추가 추출한다. |
| E3 | 공식 시정의 근거를 설명한다. 배를 수리하는 행동은 하지 않았으므로 보수 도구가 있어도 배가 자동으로 온전해지지 않는다. |

## 3. 모로를 데리고 나오는 경로

`S01-C → I03-B → P12-C → S12-B → T21-D → D22-D → S22-C → P21-A → R32-C → S31-C → F33-A → E5`

| 확인할 장면 | 읽을 때 기대하는 사실 |
| --- | --- |
| I03-B, P12-C, T21-D | 첫 미션은 오답이지만 이후 조사로 도면을 확보한다. 실패로 게임이 막히지 않는다. |
| D22-D, S22-C | 보수 도구와 수동 배수선 정비를 마친다. |
| P21-A, R32-C | 장치가 멈춰 복구로 간다. 배터리와 모로 전원을 사용해 배와 원본을 구조한다. |
| S31-C, F33-A | 모로는 잠든 상태이고 배터리는 없다. 정비 수레로 옮기는 행동과 대사가 맞아야 한다. |
| E5 | 배·원본은 온전하지만 모로는 다음 충전을 기다린다. 물건을 구했다는 사실이 발송까지 마쳤다는 뜻은 아니다. |

## 함께 확인할 갈림길

- I04를 거친 T22는 요청 수신을 다시 부정하지 않는다. I04에서 배터리나 도면을 골랐어도 들은 사실은 남는다.
- R31/R32의 밀봉은 회수가 아니다. 사흘 뒤 전문가가 열기 전 원래 배를 내일 행사에 쓰지 못한다.
- F31의 손상 배 수리는 보수 도구를 실제로 가진 경우에만 성공한다. 읽을 수 없는 원본은 수리 대상이 아니다.
- F32의 공식 시정은 서명 또는 규약·실행/요청 자료 조합을 따른다. 입증 자료 부족과 나래의 개인 의사 확인을 혼동하지 않는다.
- E2/E4/E6도 선택에 따른 결말이다. 본문을 짧은 실패 알림으로 대체하지 않는다.

## 검토 결과

2026-10-27 세 대표 경로와 I04→T22, E2/E4/E6를 분담해 읽었다. S22에서 인용 전에 전시 문구를 먼저 제시하고, R32에서 도면 미보유 팀도 도면을 펼치던 서술을 고쳤다. E6의 미확보 자료·이동하지 않은 모로 서술도 상태에 맞게 보완했다. 현재 경로에서 추가 연결 모순은 찾지 못했다.

이 단계는 원고 읽기 검토다. 실제 브라우저에서의 전 선택·조건부 결과 실행은 별도 리허설 기록에 남긴다.
