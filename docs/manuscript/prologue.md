# 프롤로그 — 마지막 야간 관람

플레이어는 마지막 관람에 초대받은 손님으로 로비에 들어와, 초대장과 윤서를 직접 찾아본 뒤 첫 전시실로 걸어간다.

## 원고와 행동

전체 실행 원고의 단일 원본은 [opening.mjs](../../src/content/opening.mjs)의 `openingContent()`다. 본문을 별도로 복사해 관리하지 않는다.

1. **로비 입장:** 역할과 장소를 짧게 소개한다. 안내대로 직접 이동한다.
2. **초대장 조사:** 마지막 관람일과 윤서를 찾아야 하는 이유, 안내지의 ‘이 물건이 돌아갈 곳’ 빈칸을 읽는다.
3. **윤서와 인사:** 초대장 읽기를 끝낸 뒤 윤서에게 접근한다. 관장과 안내 로봇을 소개받고 첫 전시품을 보러 가기로 한다.
4. **전시실 이동:** 북쪽 문과 복도를 지나 제1 전시실에 실제로 도착한다. 관람을 생략하는 시간 점프는 없다.
5. **S01 합류:** 진열장을 조사해 실종을 발견하고, 모로의 등장·윤서의 부탁·내일 일정을 확인한 후 첫 추리와 경로 선택을 한다.

## 공개와 저장

- 종이배 실종과 젖은 종이, 반환 규약과 나래의 사연은 각각 본편에서 발견한다. 폐관 이유·방문객 직업·과거 인연은 새로 만들지 않는다.
- 모로는 로비에서 직접 등장하지 않는다. 이름과 역할만 윤서를 통해 듣는다.
- 새 게임의 버전은 `museum-map-4`다. 도입은 선택 결과·자원·주요 결정 수를 바꾸지 않는다. 중단과 재개도 기존 사건 저장으로 처리한다.
- 조사 중 현장으로 나오면 미완료 상태다. 마지막 메시지까지 읽어야 관찰을 기록하고 다음 대상을 공개한다.
- 건너뛰기는 재플레이용이며 S01 조사와 추리를 대신 완료하지 않는다. 기존 버전 저장은 기존 시작·조사 규칙으로 재생한다.
- 구형 [다섯 페이지 원고](../../public/prologue.mjs)는 이전 구현 이력이다. 현재 새 게임의 실행 원고로 사용하지 않는다.

구체적인 입력·실패·화면 계약은 [도입 수정 계획](../narrative/onboarding-revision.md)을 따른다.
