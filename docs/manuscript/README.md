# 전체 스토리 원고

이 원고는 《폐관 후의 박물관》을 메시지로 읽고, 단서를 제시하고, 팀이 행동을 결정하며 진행하는 데 사용한다. 세 팀은 같은 밤의 서로 다른 가능성을 플레이한다.

## 읽는 방법

- 한 팀은 모든 원고를 순서대로 읽지 않는다. 선택한 경로의 11장면과 해당 엔딩을 읽는다.
- 새 게임은 로비에서 초대장을 조사하고 윤서를 만나 전시실로 걸어가는 O00 프롤로그로 시작한다. 저장한 기록은 프롤로그 도중에도 그 지점에서 이어간다.
- ‘본문’ 뒤 A~D 중 선택한 결과만 읽고 다음 장면으로 이동한다. 조건부 대사는 실제 상태와 일치하는 것만 읽는다.
- **팀** 대사는 확정한 행동을 표현하는 원고다. 자유 대화의 질문 예시는 자동 발송하지 않는다.
- 모로·윤서와의 현장 대화도 메시지로 표시한다. 나래와는 문자로 연락한다. 음성이 없어도 사건과 감정을 이해할 수 있도록 쓴다.
- 제작자용 조건·상태 ID·목적지 표시는 게임의 내부 연결 정보다. 플레이 화면에는 자연스러운 안내와 행동으로 보여 준다.
