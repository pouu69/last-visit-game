# 행사 진행자 안내

11명이 세 팀으로 나뉘어 각자 내린 선택을 비교하는 행사다. 각 팀은 같은 밤의 독립된 가능성을 플레이하므로 다른 팀의 배터리를 빼앗거나 답을 기다릴 필요가 없다.

## 시작 전

4명·4명·3명으로 나누고 각 팀에서 화면 조작, 대사 읽기, 단서 기록 역할을 맡는다. 역할은 중간에 바꿀 수 있다. 한 팀이 하나의 진행 화면을 함께 보는 방식을 기준으로 만들었다. 동일한 팀 세션을 여러 기기에서 동시에 조작하는 협업 편집 기능은 없다.

정적 배포 주소나 로컬 미리보기에서 시작 화면과 준비된 질문을 확인한다. AI·API 키·게임 서버는 필요하지 않다. 진행은 각 브라우저에 저장되므로 다른 기기로 옮기거나 행사 기록을 모을 때는 메뉴에서 기록 파일을 내려받는다.

읽는 속도에는 벌점이 없다. WASD/방향키나 바닥 클릭으로 이동하고, 가까운 사물과 NPC를 조사한다. 지도에서 다음 목적지를 확인한다. 빠르게 누르는 능력보다 단서를 대조하고 선택의 대가를 이해하는 것을 강조한다. 필수 관찰과 추리를 마쳐야 다음 행동을 확정할 수 있다.

사물 조사 때는 카메라가 가까워진다. 휠이나 두 손가락으로 확대하고, 우클릭·Shift 드래그 또는 두 손가락 이동으로 시점을 돌린다. 화면의 `시점 조절`에서도 같은 조작과 시선 높이 조절을 할 수 있다. 길을 잃으면 `기본 시점으로`를 누르고 지도를 펼친다.

## 권장 진행

| 구간   | 계획 시간 | 진행                                        |
| ------ | --------- | ------------------------------------------- |
| 안내   | 10분      | 조작·공동 목표·질문/힌트 사용을 설명한다.   |
| 플레이 | 55분      | 3장, 11회 결정, 각 팀의 결말까지 진행한다.  |
| 비교   | 25분      | 각 팀의 물품 상태와 마지막 행동을 비교한다. |

이 시간은 행사 계획값이다. 실제 참가자의 읽기 시간과 재미는 아직 사람 리허설로 측정하지 않았다. 긴 토론이 나오면 대화를 재촉하기보다 비교 시간을 조절한다.

## 막혔을 때

- 도장·운반 경로·인양 순서 퍼즐에는 힌트 세 단계가 있으며 사용해도 벌점이 없다. 제출 전에는 배치를 고칠 수 있다. 최종 오답 제출 후에는 실패 결과와 복구 경로로 이어진다. 추리 대조의 오답은 근거를 다시 보고 고칠 수 있다.
- NPC에게는 장면별 준비된 질문과 보유 단서에 맞는 추궁을 고른다. 자동 저장 경고가 보이면 플레이를 이어가되 메뉴에서 기록을 내려받아 보관한다.
- 새로고침 뒤 `저장한 이야기 이어보기`에서 팀을 선택한다. 이동 중 다시 열면 출발 방에서 목적지까지 다시 걷는다. 저장 파일은 별도 세션으로 불러오므로 기존 진행도 남는다. 변조된 기록은 거부한다.
- 모로가 잠드는 것은 방전이며 사망이 아니다. 남은 배터리나 다음 날 충전으로 이어질 수 있다. 밀봉한 함은 사흘 뒤 개봉하므로 원래 배를 다음 날 아침에 보낼 수 없다.

## 결말 비교

같은 브라우저에서는 `팀별 결말 보기`를 사용한다. 각 팀이 별도 기기에서 진행했다면 기록 파일을 내려받아 진행자 브라우저의 해당 팀에 불러온다. 기존 진행자 기록을 보존해야 한다면 먼저 내려받는다.

1. 실제로 지킨 것은 무엇인가? 종이배·원본 장부·모로의 상태를 구분한다.
2. 무엇을 알고 있었고 무엇을 정식 자료로 보존했는가? 구두 인정과 서명 진술의 차이를 본다.
3. 같은 자료가 있어도 다른 행동을 골랐다면 어떤 결말이 되었을까?
4. 배를 지키는 일과 배를 보내는 일은 어느 선택에서 달라졌는가?

정답 엔딩을 하나로 정하지 않는다. 익명 전시, 편지, 현장 인계도 선택한 행동과 남긴 책임을 가진 결말이다.
