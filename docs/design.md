# 폐관 후의 박물관 — 아직 오지 않은 날들

11명이 세 팀(4·4·3명)으로 같은 사건을 조사하고, 서로 다른 판단을 비교하는 한국어 협동 게임북을 제작한다. 참가자 준비·참가비·행사 중 API 호출은 없다. 앞선 대화의 「처음부터 끝까지 다 만들어봐」를 제작 위임으로 해석하며, 아래 세부 사항은 제작자의 판단이다.

## 경험과 범위

도입 10분, 팀별 플레이 목표 55분, 결말 비교 25분. 55분은 미실측 목표이며 3~4명 실제 플레이로 조정해야 한다. 12번의 결정(미션 두 번 포함), 매 결정 정확히 A–D 네 가지 선택. 개인 점수·탈락·강제 타이머·실시간 벌칙 없음. 합의가 막히면 투표 후 동률일 때 번갈아 결정권을 맡는다. 서로 다른 결말은 보장하지 않는다.

서버와 라이브 AI를 쓰지 않는 고정된 원작이다. 생성 중단·맥락 손실을 피하고 사건의 진실과 단서의 일관성을 검증하기 위해 택한다. AI 공동 창작이라는 초기 기획에서, 미리 제작한 게임북을 함께 플레이하는 방향으로 바뀐 범위다. 다음 장면의 본문·선택·결과는 현재 경로와 소지품에 맞게 변한다.

## 사건의 불변 사실

기증자 강나래가 맡긴 종이배는 돌아가신 아버지를 되살리려는 물건이 아니다. 아버지와 미뤄 온 약속, 이웃들과 종이배를 띄우는 날을 실제로 열자는 약속이다. 안내 로봇 모로가 원래의 반환 규약에 따라 종이배를 반환실로 옮겼다. 폐관 정리에서 미수령품이 소거되는 것을 막기 위해서다. 관장 윤서는 전시를 유지하려고 반환 규약을 감췄다. 출입문은 잠기지 않는다. 무엇을 지키고 무엇을 돌려줄지 선택하는 모험이다.

## 전이 계약

입력: 팀 번호 1~3, 앞뒤 공백 제거 후 1~20개 유니코드 코드포인트의 팀 이름, A~D 선택 ID. 제어문자를 거부한다. 출력: 새로운 상태 또는 구체적인 오류를 담은 실패 값. 이전 상태는 변경하지 않는다. 엔진은 동기·결정적이며 시간·랜덤·DOM·저장소 접근이 없다. 유효하지 않은 선택, 종료 후 선택은 상태를 바꾸지 않는다. 한 화면에서 선택을 미리 고른 뒤 확정하고, 결과를 읽은 다음 다음 장면으로 넘어간다. 재입장 시 마지막 확정 결과를 다시 보여준다.

상태: 단계 0~12, 조사 경로, 마지막 제안, 기록의 서명 방식, 단서/물건 집합, 선택 이력. 소지품은 다음 장면과 결말 조건에 반영한다. 원본 기록은 8번째 결정에서 훼손되면 새로 만들어 복구할 수 없다. 모든 선택의 구체적인 결과는 모험 기록과 인쇄물에 남는다.

## 결정과 결말

빈 진열장 → 네 조사 경로 → 수장고 암호(미션1) → 가져갈 기록 → 모로의 진실 → 관장의 고백 → 빛의 문장(미션2) → 침수 보관함에서 구조 → 기증자의 대답 → 최종 제안 → 기록의 서명 → 최종 결정.

반환: 배+주소가 있으면 「강으로 돌아간 약속」, 그렇지 않으면 「다음 사람에게 보내는 편지」. 전시: 원본+공개 동의가 있으면 「비어 있는 진열장의 빛」, 그렇지 않으면 「이름 없는 창문」. 공동 반환 창구: 「내일을 여는 접수대」. 해산: 「문을 연 박물관」. 마지막 선택 전 현재 조건과 예상 결과를 보여준다. 우열이나 정답 엔딩은 없다.

## 실패와 복구

미션은 화면 안의 단서만으로 풀 수 있고 단계별 힌트를 제공한다. 오답도 즉시 이유와 실제 해설을 보여주며 진행한다. 얻지 못하는 단서를 사전에 알린다. 저장은 버전·선택 이력·비암호학적 체크섬을 담는 JSON. 20KB 이하, 최대 12회 선택만 받고 처음부터 재실행해 검증한다. 체크섬은 손상 감지용이며 악의적 편집을 막는 보안 기능이 아니다. 저장소 사용 불가·용량 초과·깨진 파일·지원하지 않는 버전은 구체적인 복구 안내를 표시한다. 파일 복원과 새 시작은 기존 기록이 있으면 덮어쓰기 확인을 거친다. 팀 번호마다 별도 자동 저장한다. 탭 간 충돌은 최신 저장을 덮어쓰지 않고 재불러오기/다른 팀 시작으로 안내한다. 팀 간 자동 동기화는 없다.

결말 PNG와 전체 기록 인쇄, 완료한 세 팀 JSON을 모아 비교·공동 기록 PNG 저장을 제공한다. 파일은 로컬에서만 처리한다. 취소한 파일 선택은 아무 변화 없음. 잘못된 비교 파일은 기존 비교 목록을 바꾸지 않는다. 이미지 저장 실패는 인쇄 대안을 안내한다. 초기화는 확인 후 해당 팀 기록만 비운다.

## 미감과 접근성

야간 박물관의 전시 안내책. 원작 SVG 삽화: 청록색 공간, 금빛 진열장, 접힌 종이와 유리의 기하학. 잉크 #173e43, 밤 #0f2d32, 종이 #f4f1e7, 유리 #afc9bf, 빛 #e5b86a, 자주 #795967. 제목 플랫폼 명조, 본문 플랫폼 고딕. 삽화가 화면의 중심이며 기능은 조용하게 둔다. 본문 왼쪽 정렬, 선택은 큰 클릭 영역. 모바일·키보드·가시적 포커스·줄어든 움직임·인쇄 대응. 외부 폰트나 이미지 없음.

## 검증

엔진 단위·경계·저장 손상·불변성 검사, 이력을 제외한 상태 동치로 도달 가능한 모든 상태를 탐색해 매 장면 네 선택/종료/6엔딩 확인, 두 미션을 독립 풀이로 검증한다. 실제 브라우저에서 파일 직접 실행, 완주, 저장/복원, 비교, PNG, 모바일, 콘솔과 외부 요청을 확인한다. 빌드·구문/정적 검사·포맷·타입 검사 결과를 보고한다. 재미·읽기 난이도·55분은 인간 플레이테스트가 남는다.
