# 방 안의 NPC 행동

모로와 윤서는 플레이어의 위치를 목적지로 삼지 않고, 같은 방 안의 안전한 지점과 현재 공개된 조사 대상 주변을 고른다. 모로는 점검, 윤서는 배회·휴식이 더 자주 선택된다. 주변 사물 쪽으로 이동한 뒤 그 방향을 바라본다. 이 행동은 조사·선택·동행의 대본을 바꾸지 않는다.

플레이어가 가까워지면 잠시 멈춰 바라보고, 대사 간격이 허용되면 인사한다. 조사 요청이 들어오면 NPC를 현재 위치에 멈추고 플레이어가 그곳으로 다가간다. 따라서 배회 범위를 상호작용 거리 안으로 제한할 필요가 없다.

혼잣말은 `public/npc-ambient.mjs`의 작성된 텍스트를 말풍선으로 보여준다. 일반 행동과 눈에 보이는 침수 상황을 구분하고, 정답이나 미확인 단서를 말하지 않는다. 개별 NPC는 18–27초 간격으로 말하며, 전역 8초 간격과 한 개의 말풍선으로 겹침을 줄인다. 같은 대사를 연속으로 고르지 않는다. 음성 합성은 사용하지 않는다.

대화·퍼즐·메뉴·이동 중에는 새로운 배회와 혼잣말을 멈춘다. 잠든 모로나 운반 중인 모로도 혼잣말을 하지 않는다. 충돌로 막힌 배회 경로는 버리고 잠시 뒤 다시 고른다. 목적지와 경로가 같은 방 안인지 확인한다.

브라우저의 `museumDiagnostics()`는 각 NPC의 `activity`, `ambientPath`와 표시 중인 `ambientSpeech`를 제공한다. 이 값은 연출 확인용이며 게임 저장·증거·선택에는 영향을 주지 않는다.
