# 변경 기록

## 추가

- 전체 3장·84선택·6엔딩을 전체 화면 3D 게임에 연결했다. 인물 대화와 내레이션·단서·힌트를 구분하고, 실제 NPC AI 질문·단서 추궁·팀별 저장과 결말 비교를 지원한다.
- 기존 T22의 선행 인정·결정론적 추궁 규칙을 전체 게임에서 재사용한다. 모델이 이야기의 소지품이나 이동을 직접 확정하지 않는다.

## 수정

- UI-1: 대화 기록이나 선택 창을 연 상태에서 방향키로 뒤쪽 대사가 넘어가지 않도록 했다.
- AI-1: 단서를 보유한 것과 실제 추궁에서 그 단서를 근거로 사용한 것을 구분했다.
