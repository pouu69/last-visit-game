# 오디오 설계

## 목표

폐관 후 박물관의 조용한 분위기를 유지하면서 이동·조사·선택에 짧고 분명한 피드백을 준다. 별도 음원 파일이나 외부 서비스 없이 Web Audio API로 생성한다. 브라우저 자동재생 제한을 지키기 위해 첫 사용자 입력 뒤 오디오를 시작하고, 탭이 숨겨지면 오디오 컨텍스트를 일시 정지한다.

## 믹서

```text
Destination
└─ Master
   ├─ Music     느린 5음 음계 모티프
   ├─ Ambience  저역 통과된 박물관 공기음
   ├─ SFX       발걸음·조사·진행 확인
   └─ UI        버튼 클릭
```

모든 그룹은 Master를 거친다. 슬라이더는 0–100으로 표시하고, 제곱 곡선으로 체감 가능한 조절 폭을 넓힌 뒤 Web Audio의 선형 GainNode 값으로 바꾼다. 0은 완전 무음이다.

## 입력 피드백

| 입력 | 소리 |
| --- | --- |
| 버튼 누름 | 짧은 고음 클릭 |
| 이야기 진행·확정 | 클릭보다 조금 길고 높은 확인음 |
| WASD·방향키·바닥 클릭으로 이동 | 340ms 간격 제한이 있는 낮은 발걸음음 |
| 조사 대상 가까이에서 E 또는 조사 실행 | 짧은 상승음 |

## 사용자 설정

타이틀 화면의 **Sound Settings** 또는 게임 메뉴에서 Master, Music, Ambience, SFX, UI를 각각 조절한다. 값은 `museum-audio-settings-v1` 키로 브라우저에 저장한다. 초기값은 각각 80, 44, 40, 62, 48이다. 실제 음성 대사는 없으므로 Voice 그룹은 현재 믹서에 두지 않았다.

## 튜닝 메모

현재 음색은 합성 프로토타입이다. 헤드폰과 스피커에서 배경음의 체감 크기, 발걸음의 반복 피로도, 조사음과 버튼음의 구분을 청취 검토한 뒤 기본 음량과 파형을 조정한다. 실제 음원으로 교체할 때도 그룹 라우팅과 사용자 설정은 유지한다.
