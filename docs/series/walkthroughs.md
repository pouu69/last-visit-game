# v2 원고 읽기와 반례 진행

2026-10-28. 작성자가 선택한 결과와 조건부 문장만 이어 읽은 모의 진행이다. 새 게임을 구현하거나 브라우저에서 실행한 기록이 아니다. [이전 읽기 기록](archive/v1.1/walkthroughs.md)은 보관본이며 현재의 선택 결과를 증명하지 않는다.

중간편 표기는 ‘조사 / 판단 / 시간 배분 / 실행’ 순서다. 마지막은 ‘현장 조사 / 운영안 / 보완 / 실제 실행’ 순서다. 각 경로의 1편 상태는 기존 엔딩 조건에 맞춰 인계하고, 준비 기간 회신에서만 배·장부의 후속 상태를 갱신한다.

## 1. 여섯 방문 순서

| 경로 | 방문 순서 | 2편 N21/N23/N24/N25 | 3편 V31/V33/V34/V35 | 4편 W41/W43/W44/W45 |
| --- | --- | --- | --- | --- |
| P1 | 1 E1 → 2 → 3 → 4 → 5 | D / C / A / A | B / A / A / A | A / B / B / A |
| P2 | 1 E2 → 2 → 4 → 3 → 5 | C / C / B / B | D / A / B / D | C / B / B / B |
| P3 | 1 E3 → 3 → 2 → 4 → 5 | B / B / B / C | A / B / A / C | D / C / B / D |
| P4 | 1 E4 → 3 → 4 → 2 → 5 | B / D / A / D | B / A / A / B | D / A / A / C |
| P5 | 1 E5 → 4 → 2 → 3 → 5 | B / A / A / A | D / C / B / C | B / D / B / D |
| P6 | 1 E6 → 4 → 3 → 2 → 5 | C / C / B / B | A / D / A / D | A / B / A / C |

E1/E2는 역, E3/E4는 극장, E5/E6는 수리소로 먼저 이어진다. 중간 엔딩의 우선순위는 기존대로이며 이미 마친 편은 건너뛴다.

### P1 — 준비를 이어 공개 왕복을 실행

역에서는 문정 동행을 먼저 구하고 추가 답사에 마지막 시간을 쓴다. 극장에서는 악보와 시계 판단으로 신호를 확인한 뒤 정연과 대화한다. 수리소에서는 눈높이 조사와 올바른 진단으로 고정형을 준비하고 이든의 인수 교육을 한다.

**최종 인계:** 길 완료 / 신호 완료 / 고정등 완료 / 인수 완료 / 정연 참석.

**5편:** R51-B → R52-B → R53-D → R54-B-A. 인수 재확인으로 다른 상태를 새로 얻지는 않는다. 이미 준비가 돼 있어 한 작은 대열로 실제 왕복한다. 고정등은 쉼터에 남는다. 대열이 돌아온 뒤 별도 귀가할 사람까지 확인한다.

**판정:** ‘왕복길의 첫날’. 1편에서 띄운 배를 다시 쓰지 않는다. 고정등으로 이동등 효과를 내거나 정연에게 독창을 맡기지 않았다.

### P2 — 움직이는 물품과 공개 신호를 조합

역의 화물길 조사·정답으로 표지를 확인하고 문정 동행도 약속받는다. 수리소에서는 운반 조사·정답으로 이동형을 준비하고 인수를 교육한다. 극장에서는 먼저 정연을 손님으로 초대한 뒤 공개 신호에 시간을 쓴다. 개인 청취 파일은 가져오지 않는다.

**최종 인계:** 길 완료 / 신호 완료 / 이동등 완료 / 인수 완료 / 정연 참석.

**5편:** R51-A → R52-C → R53-D → R54-C-B. 필요한 세 준비와 이동 물품이 있어 세 접점의 공개 이동 모임을 실행한다. 역할은 문정=길, 소희=정지·재개, 나래=쉼터, 여러분=합류·귀환 확인으로 나뉜다.

**판정:** ‘한곳에 모이지 않는 모임’. 밀봉됐던 배의 사흘 뒤 인계는 별도 회신으로만 처리한다. 당일에 배를 구조·발송했던 것으로 바꾸지 않는다.

### P3 — 관계를 택한 결과와 두 군데의 미완료

극장에서는 파형 조사 후 시각을 잘못 맞힌다. 정연과의 대화를 골라 참석은 확인하지만 공개 신호 시험은 남긴다. 역에서는 받침을 조사하고 귀환 배치를 틀린 뒤, 답사 대신 문정 동행에 시간을 쓴다. 최종 방식은 약도이므로 동행 약속만으로 독립 약도 확인이 완료되지는 않는다. 수리소는 주간 운영으로 마친다.

**최종 인계:** 길 미완료 / 신호 미완료 / 주간 조건 충족 / 인수 완료 / 정연 참석.

**5편:** R51-C → R52-B → R53-A. 약도를 실제 대조해 길은 완료하지만 신호가 남는다. 공개 왕복 정규 본문은 읽지 않는다. 마지막 변경 선택 A로 한자리 모임을 실제 열고 ‘강가의 빈자리’로 간다.

**판정:** NPC가 남은 신호를 덤으로 해결하지 않는다. 정연이 참석한다고 공개 왕복이 자동 가능해지지도 않는다. 관계 선택을 비난하지 않으며, 함께 앉는 모임은 성립한다.

### P4 — 먼저 틀렸어도 특정 문제를 보완해 회복

극장은 악보·올바른 시계 대조로 신호를 마치고 정연을 초대한다. 수리소에서는 진단을 틀렸지만 형태 시험을 골랐고 최종 물품은 주간 손표지다. 역에서는 잘못된 배치를 추가 답사로 고쳤으나, 최종 선택을 사람 안내조로 바꾼다. 문정 동행 확약은 없어 안내조 편성은 미완료다.

**최종 인계:** 길 미완료 / 신호 완료 / 주간 손표지 완료 / 인수 완료 / 정연 참석.

**5편:** R51-D → R52-B → R53-A → R54-B-B. 문정이 안내조의 빈 역할을 받아 실제 시범한 뒤 길 준비가 완료된다. 두 차례의 왕복을 순서대로 하고 다음 안내자는 문정 곁에서 배운다.

**판정:** ‘왕복길의 첫날’. 오답이 영구 실패가 아니며, 무엇을 고쳤는지가 회복의 근거다. 완료한 답사를 사람 동행 확약과 같은 것으로 세지 않았다.

### P5 — 준비가 좋아도 선택한 형식의 한계는 남음

수리소에서 인수 교육과 주간 운영을 고른다. 역에서는 동행 약속 없이 사람 안내 방식을 정한다. 극장은 시계 판단을 틀렸지만 공개 신호 시험을 골라 직접 회복하고, 앞선 초대로 정연 참석도 확인했다.

**최종 인계:** 길 미완료 / 신호 완료 / 주간 조건 충족 / 인수 완료 / 정연 참석.

**5편:** R51-A → R52-C → R53-A. 안내조를 보완하면 공개 왕복 B는 가능하다. 그러나 이동등·손표지는 없다. C의 정규 실행 대신 변경 선택 A의 ‘이동 접점을 줄인다’를 읽고 한 대열로 왕복한다.

**판정:** ‘왕복길의 첫날’. 선택하지 않은 물품을 지급해 세 접점을 열지 않는다. 처음 목표를 줄이되 실제 실행 결과를 남긴다. 이 경로의 모로는 봉인된 접속부를 열지 않고 동행할 수 있다.

### P6 — 이번 행사보다 다음 사람의 인수를 우선

역 표지는 확인했고, 극장에서는 신호 시험 대신 정연과 대화를 선택해 공개 신호가 남는다. 수리소는 손표지를 만들었지만 형태 시험에 시간을 써 이든의 다음 인수는 미완료다. 모로는 맡기고 간다.

**최종 인계:** 길 완료 / 신호 미완료 / 손표지 완료 / 인수 미완료 / 정연 참석.

**5편:** R51-B → R52-D → R53-D → R54-D-B. 인수 교육으로 이든이 다음 점검을 받는다. 공개 신호 상태는 미완료 그대로다. 담당자가 가까이 붙는 작은 시범을 마친 뒤 다음 안내 교육을 정한다.

**판정:** ‘다음 사람이 아는 길’. 인수를 마쳤다고 이번 공개 대열 검증까지 통과시키지 않았다. 모로의 현장 대사를 생략해도 진행한다.

## 2. 선택 하나를 바꾼 대조

### P3의 V34-A만 B로 바꾸기

정연의 참석은 보류되고 공개 신호가 완료된다. 다른 선택은 그대로 두고 R53-A로 길을 보완하면 길·신호·주간 조건이 모두 충족된다. 이때는 B의 공개 왕복을 실행할 수 있다.

**확인:** 중간 선택 하나가 참석 인물과 최종 실행 가능 범위를 함께 바꾼다. 정연이 안 왔다고 이야기를 막지는 않는다. V31-D로 먼저 초대했거나 악보·영상 조사와 올바른 판단을 했다면 둘 다 얻는 경로도 있으므로 ‘관계와 성공은 양립 불가’라는 규칙은 아니다.

### P6의 R53-D만 B로 바꾸기

신호는 완료되지만 다음 점검 인수는 여전히 미완료다. 목표를 B로 잡았다면 공개 왕복은 가능하고 다음 점검은 태오·교육 동행으로 남는다. D 목표를 유지하면 작은 시범으로 마칠 수도 있다.

**확인:** 마지막 보완이 모든 빈칸을 지우지 않는다. 오늘 규모와 다음 인수 중 어디에 썼는지가 남는다.

## 3. 모두 틀리는 반례

역 B/A/B/B, 극장 A/D/A/A, 수리소 D/A/B/A를 읽었다. 길·신호·고정형 장비 세 가지가 모두 미완료다. R53의 어느 한 선택도 세 가지를 전부 완료하지 못한다. 공개 왕복·세 접점 이동의 정규 실행은 열리지 않는다.

한자리 모임 A 또는 작은 동행 시험 D로 전환하면 이번 모임의 도착·활동·귀환·정리를 마친다. 다섯 이야기를 모두 경험했다는 조건은 유지한다. 이때 독립 운영·공개 대열·미점검 장비 사용 성공을 쓰지 않는다.

## 4. 진행 규칙을 열거한 대조

임시 분석으로 원고의 우선순위 표와 준비 판정을 대조했다. 저장소에 게임 코드나 테스트 코드를 추가하지 않았다.

| 범위 | 확인 결과 |
| --- | --- |
| 1편 6엔딩 × 중간편 각 4엔딩 | 384개 조합 모두 중간 세 편을 한 번씩 방문하고 5편 도달 |
| 방문 순서 | 6종, 각 순서에 64개 엔딩 조합 |
| 중간편의 조사4 × 판단4 × 시간2 × 실행4 | 편당 128개 선택열을 준비 상태로 대조 |
| 최종 판정에 필요한 서로 다른 인계 상태 | 역 8종 / 극장 12종 / 수리소 10종, 합성 960종 |
| 인계 960 × 보완4 × 운영안4 × 마지막 행동2 | 30,720개 최종 판정 사례에서 종료 가능한 결과 존재 |
| 공개 왕복·이동 모임 판정 | 준비 조건 미충족 상태에서 정규 B/C 엔딩을 얻는 사례 없음 |
| 최종 결과 분포 | A 13,152 / B 3,680 / C 1,472 / D 12,416. 중복 제거한 상태·결정 사례의 수이며 이용자 선택률이 아님 |

이 열거는 준비 상태와 진입 조건을 확인한다. 30,720개 원고를 사람이 모두 읽었다는 뜻이 아니다. 실제 읽기는 여섯 대표 경로·선택 변경 두 건·모두 실패 반례와 조건부 장면 대조다. 인물의 재미·체감 난도·모든 동시 역할을 수학적으로 증명한 수치로 쓰지 않는다.

## 5. 재독 중 추가로 고친 것

- 시간 배분에서 초대·출고를 보류해 놓고 결말 대사가 자동 약속하던 문장을 조건부로 고쳤다.
- N23 오답 뒤 ‘마지막 시험에 동행한다’던 무료 보완을 제거했다. 도면 수정과 현장 검증을 구분했다.
- 정연을 먼저 초대한 경로에서는 V34에서 같은 참석 의향을 다시 미정으로 만들지 않는다.
- 공개 시험 중 정연은 안쪽에서 자료를 정리한다. 이미 극장을 떠난 뒤 개인 청취에서 갑자기 다시 등장하지 않도록 이동을 고쳤다.
- 시험 대기 등은 수리소에서 이든의 수레로 가져오는 이동을 명시했다. 견본 반입과 사용 승인을 구분했다.
- C를 줄여 B/A/D로 갈 때는 이동과 모임을 실제 실행한 뒤 해당 엔딩으로 간다. 다른 방향의 추가 결정은 다시 읽지 않는다.
