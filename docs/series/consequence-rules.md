# 선택 결과와 최종 실행의 기준 — v2

집필용 기준이다. 실행 엔진·저장 형식을 구현한 문서가 아니다. 플레이어에게는 각 결정 앞의 대사와 비용 안내로 전달한다.

## 1. 중간편의 네 결정

**조사 → 근거 판단 → 남은 시간 배분 → 실행 방식**으로 진행한다. 기존의 세 결정에 시간 배분을 추가했다.

오답을 골라도 핵심 진실과 안전한 진행 방법은 안다. 다만 추가 시험까지 마친 상태는 아니다. NPC의 설명과 장비·운영의 검증 완료를 구별한다. 힌트를 사용해 맞힌 판단은 처음부터 맞힌 것과 같다.

남은 시간은 현실의 제한 시간이 아니다. 담당자와 예약한 방문 작업의 마지막 한 구간이다. 충분히 읽고 토론해도 줄지 않는다. 선택 전에 두 작업을 모두 마칠 수 없음을 알리고, 못 한 작업은 마지막 편에서 한 번 보완하거나 이번 실행 범위를 줄인다. 뒤에 방문했다고 이 기회를 잃지는 않는다.

## 2. 준비 상태 판정

| 상태 | 완료되는 조건 | 미완료의 의미 |
| --- | --- | --- |
| 역의 왕복 현장 확인 | N21-A 또는 C를 조사하고 N23-C로 판단했거나, N24-A의 추가 답사를 실행 | 길이 위험하다는 뜻은 아님. 물품만 보고 양방향을 찾아가는 독립 시험이 미완료 |
| 문정의 첫날 동행 확약 | N21-D 또는 N24-B | 모임에 문정이 개인 손님으로 올 수는 있으나 안내 근무를 약속한 것은 아님 |
| 극장의 공개 신호 시험 | V31-B 또는 C를 조사하고 V33-A로 판단했거나, V34-B에서 공개 시험 | 손동작의 뜻은 알지만 여러 위치에서 되돌려 확인하는 연습이 미완료 |
| 정연의 일반 참석 의향 확인 | V31-D 또는 V34-A | 참석을 보류함. 새 독창 허락과는 어떤 경우에도 별개 |
| 고정등 현장 사용 준비 | W41-A 또는 B를 조사하고 W43-B로 진단했거나, W44-A에서 형태 시험 | 정상 전구와 고정쇠가 있다는 것만으로 받침·차광까지 검증되지는 않음 |
| 이동등 현장 사용 준비 | W41-B 또는 C를 조사하고 W43-B로 진단했거나, W44-A에서 형태 시험 | 조립 견본은 있으나 사용 중인 조명으로 출고하지 않음 |
| 다음 점검 인수 | W41-D 또는 W44-B | 이번 담당자 시범과 다음 회차를 스스로 맡는 것은 다름 |

핵심 사실과 준비 상태는 분리한다. 예를 들어 극장 판단에 실패한 뒤에도 정연이 독창을 지워 달라고 한 이유는 안다. 신호 시험을 추가로 고르면 관계를 다시 묻지 못한 채 떠날 수는 있지만, 정연을 모르는 사람처럼 쓰지 않는다.

## 3. 엔딩별 실제 인계

| 엔딩 | 완료 판정 | 그렇지 않으면 남기는 결과 |
| --- | --- | --- |
| 2-A 철거한 화살표 | 문정 동행 확약이 있으면 안내조 확정 | 옛 판은 보관하고, 첫날 안내 담당은 현장 보완 대상으로 남김 |
| 2-B 두 겹의 표지 | 왕복 현장 확인이 있으면 양쪽 표지 사용 가능 | 문구·받침은 준비했으나 귀환 표지는 ‘설치 시험 대기’. 독립 안내 완료 아님 |
| 2-C 주머니 속 약도 | 왕복 현장 확인이 있으면 독립 약도 | 동행 확인용 약도. 혼자 찾아오라는 안내로 배포하지 않음 |
| 2-D 함께 걷는 길 | 문정 동행 확약이 있으면 선두·후미 인계 확정 | 이동 표지는 점검하되 안내조 편성은 미완료 |
| 3-A/B/C/D | 선택한 음원·박자·카드·개인 청취와 별도로 공개 신호 시험 여부를 기록 | 준비한 표현 수단은 보존. 대열 운영에 사용할 신호 검증은 미완료 |
| 4-A/B | 각각의 고정·이동 준비가 있으면 해당 형태 출고 | 견본은 수리소에 두고 ‘사용 전 시험 필요’ 메모만 전달 |
| 4-C 손에서 손으로 | 주간용 손표지는 완성 | 조명 없음. 다음 점검 인수는 별도 기록 |
| 4-D 아직 켜지 않은 등 | 주간 운영 계획으로 마침 | 등 없음. 현장 보완으로 이 날 전기등을 새로 만들어 주지 않음 |

따라서 ‘중간편 클리어’와 ‘모든 준비 완료’는 같은 뜻이 아니다. 준비 미완료여도 그 장소의 진실을 밝히고, 실제로 물품을 보관·시범·인계해 편을 마친다. 엔딩별 다음 방문 우선순위는 그대로다.

## 4. 최종편의 네 확인 항목

- **길 준비:** 2-A/D는 동행 확약, 2-B/C는 왕복 현장 확인이 기준이다.
- **신호 준비:** 공개 신호 시험 여부가 기준이다. 개인 청취용 독창을 꺼내는 우회는 없다.
- **장비 준비:** 4-A/B는 해당 형태의 사용 준비, 4-C/D는 주간 조건 준수로 충족한다.
- **다음 점검 인수:** 이든의 인수 여부를 따른다. 이번 모임 클리어의 필수 조건은 아니다.

5편 R53에서는 길·신호·선택한 장비·다음 점검 인수 중 **한 항목**을 실제 시험·교육으로 보완할 수 있다. 이미 완료한 항목을 선택하면 그 항목을 다시 확인할 뿐 다른 미완료 항목이 자동 완료되지 않는다. 이 차이는 선택 전에 알린다.

| 최종 방향 | 준비가 충족될 때 | 부족할 때의 실제 선택 |
| --- | --- | --- |
| A 한자리 모임 | 밝은 쉼터에서 도착 안내를 맡아 실행. 장비 미완료면 그늘진 테이블 사용 안 함 | 항상 가능. 대열 왕복이나 독립 운영을 성공했다고 쓰지 않음 |
| B 공개 왕복 | 길·신호·장비 준비를 모두 확인 | A의 한자리 모임 또는 D의 담당자 동행 소규모 시험으로 변경 |
| C 세 접점의 이동 모임 | B의 준비에 더해 이동등 또는 손표지 필요. 접점별 사람에게 계속 보이는 안내를 쓸 계획 | B가 가능하면 한 무리 왕복, 아니면 D의 작은 시험. 또는 A로 전환. 즉석에서 새 이동 장비 지급 없음 |
| D 작은 첫 왕복과 다음 인계 | 담당자가 붙어 짧은 구간을 실제 시범. 부족한 장비는 사용하지 않음 | 항상 가능. 인수가 미완료면 다음 회차도 담당자 동행으로 남음 |

C의 제약은 길을 걸을 수 있느냐가 아니라, **새 참석자가 각 접점에서 합류하는 공개 이동 모임의 준비 범위**에 관한 것이다. 고정등은 A의 그늘진 테이블에 강점이 있고, 이동등·손표지는 C에 적합하다. 주간 운영은 장비를 빌리지 않는 작은 시작에 적합하다. 하나를 모든 상황의 상위 장비로 취급하지 않는다.

A와 D의 기본 도착·짧은 시범은 나래·문정·소희가 현장에서 직접 맡는다. 이것으로 독립 안내·공개 대열 검증·장비 인수까지 완료했다고 기록하지 않는다. 미완료가 여러 개여도 다섯 편의 완주는 가능하다.
