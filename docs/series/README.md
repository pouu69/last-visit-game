# 돌아가는 길 — 5편 연작 스토리

**2026-10-28 · 스토리 원고 v2 · 게임 미연결**

폐관한 박물관에서 종이배를 찾아낸 방문객들이, ‘출발 12명, 귀환 대열 11명’으로 끝난 옛 왕복길 모임의 기록을 조사한다. 모두 귀가했는데 왜 한 사람은 끝났다는 말을 듣지 못했을까. 역·극장·수리소에서 그 과정을 밝히고, 앞선 선택으로 준비한 범위 안에서 새로운 모임을 실제로 연다.

기존 《폐관 후의 박물관》 전체가 **시리즈 1편**이다. 기존의 1·2·3장은 각각 별개의 편이 아니다. 이번에 2~5편 네 이야기를 새로 썼다. 현재 실행 게임에는 반영하지 않았다.

## 원고로 진행하는 방법

1. 기존 1편의 선택한 경로와 엔딩을 읽는다. 연결 원고에서 해당 엔딩의 초대를 읽는다.
2. 각 새 편의 공통 본문을 읽고, 선택한 A~D 결과만 읽는다. ‘집필 메모’와 다른 조건의 문장은 읽지 않는다.
3. 편을 마치면 엔딩명·이동할 편·넘겨받은 결과를 적는다. 다음 편은 전체 진행 규칙에 따라 미방문 편 중에서 정한다.
4. 2·3·4편을 모두 마쳤으면 5편으로 간다. 5편의 최종 행동을 실행하고, 선택한 후일담을 읽으면 끝이다.

중간 세 편은 ‘조사 → 근거 판단 → 남은 시간 배분 → 실행’의 네 결정을 가진다. 5편은 ‘현장 조사 → 운영안 → 한 건 보완 → 마지막 실행’의 네 결정을 가진다. 준비가 부족해도 모든 편을 마칠 수 있지만, 같은 규모와 독립 운영을 얻지는 않는다. 실제 플레이 시간·재미는 사람을 대상으로 측정하지 않았다.
