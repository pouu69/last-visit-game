# 직접 읽기·모의 진행 기록

2026-10-28. 작성자가 기존 원고와 새 원고를 읽고, 선택한 결과·조건부 문장만 이어 붙여 진행했다. 실제 게임에서 새 편을 조작한 기록은 아니다. 아래 여섯 경로는 원고 기반 모의 진행이며, 수정 후 조건을 다시 대입했다.

## 진행할 때 적은 항목

각 편의 시작에는 미방문 장소와 이전 결과를 적었다. 조사 한 가지 → 판단 한 가지 → 결말 한 가지를 읽고, 선택하지 않은 단서·장비를 사용하는 문장이 나오면 중단해 고쳤다. 마지막 편에서는 도착·자리·신호·귀환 역할이 겹치는지도 확인했다.

기존 1편의 경로 표기는 원래 장면 ID다. 새 원고는 N=역, V=극장, W=수리소, R=최종편이다. R54-A-A는 ‘모임 방향 A에서 마지막 실행 A’라는 읽기 기록이며 엔진 이벤트명이 아니다.

## 경로 1 — 사람들이 찾아올 자리

**방문:** 1 → 2 → 3 → 4 → 5.

**1편:** `S01-A → I01-B → P12-B → S12-A → T21-D → D22-A → S22-B → P21-B → R31-D → S31-A → F31-A → E1`.

배·장부 온전, 모로 작동, 배터리 소비. 배는 발송·수령 뒤 첫 모임에서 띄웠다. 새 편에서 원래 배를 소지하지 않는다.

| 편 | 실제 읽은 선택 | 남긴 결과 |
| --- | --- | --- |
| 2 | N21-A → N23-C → N25-A | 발자국 조사, 직접 판독, 옛 표지는 보관하고 사람 안내 |
| 3 | V31-A → V33-A → V35-A | 파형 조사, 시계 대조 성공, 독창 없는 배경음 |
| 4 | W41-A → W43-D → W45-A | 눈높이 조사, 직접 진단, 고정 조명 |
| 5 | R51-B → R52-A → R53-B → R54-A-A | 반원 자리 마련, 늦은 참석을 받으며 배 접기 |

**이어 읽은 결과:** 2편 A의 우선순위로 극장, 3편 A의 우선순위로 수리소에 간다. 고정등은 지붕 아래 접는 테이블에 남고, 문정은 갈림점 안내를 맡는다. 정연의 독창은 없다. 배 접기를 시작한 뒤 새 도착자가 오면 멈추고 다시 시작한다. 끝에는 장비를 거두고 역 뒤뜰로 귀환한다.

**피드백과 재확인:** 초안은 고정등을 낮에 잠깐 켜 보기만 해 선택의 효과가 약했다. 수정 후에는 그늘진 테이블을 실제 비추고, 참가자가 바람을 덜 맞는 곳에서 종이를 접는다.

## 경로 2 — 배가 늦게 오고, 길은 돌아오는 이야기

**방문:** 1 → 2 → 4 → 3 → 5.

**1편:** `S01-B → I02-A → P11-C → S12-D → T22-C → D22-D → S22-B → P21-C → R32-D → S31-A → F31-A → E2`.

배·장부 밀봉, 모로 작동, 배터리 미사용, 보수 도구 보유. 도면·통로 정비는 없으므로 R32-D는 우회 구조가 아니라 밀봉이다. 첫 모임에는 원래 배가 없다.

| 편 | 실제 읽은 선택 | 남긴 결과 |
| --- | --- | --- |
| 2 | N21-C → N23-B → N25-B | 화물길 조사, 귀환 위치 오답을 동행 수정, 이중 표지 |
| 4 | W41-C → W43-D → W45-B | 운반 조사, 직접 진단, 이동 조명 |
| 3 | V31-D → V33-C → V35-D | 정연 초대, 대기/편집 구간을 바꾼 오답 수정, 개인 청취 |
| 5 | R51-A → R52-B → R53-C → R54-B-B | 안내 문구 보완, 뒤쪽 신호 확인, 순차 두 무리 왕복 |

**이어 읽은 결과:** 2편 B가 수리소를 먼저 부르고, 4편 B가 극장으로 잇는다. 준비 기간의 회신에서 사흘 뒤 봉인 개봉과 늦은 배 반환을 읽었다. 장부는 뒤에 읽을 수 있게 됐지만 1편 당일의 시정 성공으로 바뀌지 않는다. 최종편에는 이중 표지·이동등이 있고 음원은 없다. 원래 독창을 공개하지 않고 손·말 신호로 두 무리가 순차 왕복한다.

**피드백과 재확인:** 초안의 ‘한 달 뒤에도 상태 확인 중’은 사흘 뒤 인계를 약속한 1편을 약하게 만들었다. 후속 개봉·수령 장면을 추가하고, 당일 결과와 늦은 완료를 분리했다.

## 경로 3 — 목소리와 조명 없이 이어지는 모임

**방문:** 1 → 3 → 2 → 4 → 5.

**1편:** `S01-B → I02-A → P11-C → S12-D → T22-C → D22-D → S22-B → P21-C → R32-B → S31-B → F32-B → E3`.

장부 온전, 배 손상, 모로는 구조 때 방전했다가 남은 배터리로 깨어남. 서명·로그가 있어 공식 시정. 보수 도구를 가졌어도 F32에서 배를 수리한 것은 아니다. 이후 회신에서 별도 보수·반환을 읽는다.

| 편 | 실제 읽은 선택 | 남긴 결과 |
| --- | --- | --- |
| 3 | V31-C → V33-B → V35-C | 손동작 관찰, 영상 시각 오독 수정, 숫자·문자 카드 |
| 2 | N21-A → N23-C → N25-C | 길 직접 확인, 직접 판독, 접는 약도 |
| 4 | W41-D → W43-B → W45-D | 이든의 점검 인수, 성급한 출고 판단 수정, 주간 운영 |
| 5 | R51-C → R52-C → R53-D → R54-C-A | 뒤쪽 신호 위치 확인, 세 지점에 같은 인사 반복 |

**이어 읽은 결과:** 3편 C가 역으로, 2편 C가 수리소로 잇는다. 최종편의 조명은 없고 음원도 없다. 약도는 갈 때와 올 때 면을 펴며 쓴다. 숫자·문자 카드와 말 안내로 세 지점에서 멈추고 시작한다. 밝은 바깥 벤치에서 배를 접고 낮 시간 안에 끝낸다.

**피드백과 재확인:** 카드 엔딩의 초안 제목 ‘빛으로 세는 시작’은 회전등·점멸등을 기대하게 했다. ‘눈으로 세는 시작’으로 바꾸고, 카드와 지속 조명을 구분했다. 없는 등이 등장하지 않는지 다시 읽었다.

## 경로 4 — 새 박자와 손표지

**방문:** 1 → 3 → 4 → 2 → 5.

**1편:** `S01-A → I01-B → P12-B → S12-A → T21-D → D22-A → S22-B → P21-B → R31-A → S31-B → F32-C → E4`.

배 온전·미발송, 원본 장부 읽을 수 없음, 모로 작동, 배터리 미사용. 서명 근거는 있지만 발표를 스스로 미룬 경로다. E4를 ‘아무것도 입증하지 못함’으로만 해석하지 않았다.

| 편 | 실제 읽은 선택 | 남긴 결과 |
| --- | --- | --- |
| 3 | V31-B → V33-A → V35-B | 악보 조사, 직접 대조, 새 공동 박자 |
| 4 | W41-D → W43-C → W45-C | 점검 인수, 고정쇠부터 빼는 판단 수정, 손표지 |
| 2 | N21-B → N23-D → N25-D | 옛 받침 조사, 계단 출발 오답 수정, 이동 표지 안내조 |
| 5 | R51-D → R52-D → R53-A → R54-D-B | 정리 역할 확인, 짧은 실제 왕복, 다음 안내자 동행 교육 |

**이어 읽은 결과:** 극장의 새 박자 → 수리소 손표지 → 역 안내조가 된다. 수리소의 ‘극장에 맞춰 달라’는 부탁은 이미 방문한 곳이므로 완료 회신으로 교체한다. 마지막에는 짧은 실제 왕복을 먼저 마친다. 다음 날짜만 적고 끝내지 않는다. 전기등·원래 독창은 없다.

**피드백과 재확인:** 손표지가 극장 신호를 덮어쓰지 않도록 동일 의미로 맞춘다. 1편 원본 잉크 손실은 배의 늦은 반환 뒤에도 남겨 두었다.

## 경로 5 — 봉인을 유지한 안내원

**방문:** 1 → 4 → 2 → 3 → 5.

**1편:** `S01-C → I03-B → P12-C → S12-B → T21-D → D22-D → S22-C → P21-A → R32-C → S31-C → F33-C → E5`.

배·장부 온전, 배터리 사용, 모로 방전. 접속부를 봉인해 작업실에 인계했다. 연작에서 동행을 택하되 다음 날 충전 후 출발하고, 기록 추출 봉인은 유지한다.

| 편 | 실제 읽은 선택 | 남긴 결과 |
| --- | --- | --- |
| 4 | W41-B → W43-D → W45-D | 고정축 조사, 직접 진단, 주간 운영 |
| 2 | N21-D → N23-A → N25-A | 문정 동행, 귀환 표지 누락 수정, 사람 안내 |
| 3 | V31-C → V33-A → V35-C | 손동작 조사, 직접 대조, 숫자·문자 카드 |
| 5 | R51-A → R52-B → R53-C → R54-B-A | 도착 안내와 후미 신호, 작은 무리 한 번 왕복 |

**이어 읽은 결과:** 4편 D에서 역, 2편 A에서 극장으로 간다. 조명·독창·개인 약도가 모두 없는 조합이다. 모로가 새 현장을 보고 말하는 것은 가능하지만, 봉인 안의 박물관 로그를 꺼내지는 않는다. 안내는 문정과 여러분이, 신호는 소희와 보조자가 맡는다.

**피드백과 재확인:** ‘모로를 충전했다’를 ‘로그를 모두 검증했다’로 바꾸지 않았다. 사람 안내도 두 지점에 선 뒤 같은 사람이 동시에 행렬을 인솔하지 않도록, 위치 확인 후 합류해 움직이는 순서로 고쳤다.

## 경로 6 — 손상은 남고, 역할은 넘어간다

**방문:** 1 → 4 → 3 → 2 → 5.

**1편:** `S01-A → I01-B → P12-B → S12-A → T21-D → D22-A → S22-B → P21-B → R31-B → S31-D → F34-A → E6`.

장부 온전, 배 손상·미수리, 모로 작동, 배터리 미사용. 배는 별도 보수·수령 회신 뒤에 상태를 갱신한다. 모로는 맡기고 떠나는 설정을 사용했다.

| 편 | 실제 읽은 선택 | 남긴 결과 |
| --- | --- | --- |
| 4 | W41-A → W43-A → W45-C | 눈높이 조사, 모터 선주문 판단 수정, 손표지 |
| 3 | V31-D → V33-D → V35-D | 정연 초대, 장비 전체 고장 추정 수정, 개인 청취 |
| 2 | N21-C → N23-C → N25-B | 화물 주소 조사, 직접 판독, 이중 표지 |
| 5 | R51-B → R52-A → R53-D → R54-A-B | 자리 배치, 귀환 책임 인계, 첫 집결 후 공동 시작 |

**이어 읽은 결과:** 4편 C가 극장을 먼저 부르고, 3편 D가 역으로 잇는다. 이중 표지 받침은 수리소를 다시 방문해 얻는 것이 아니라 역의 행사 물품을 빌린다. 녹음 파일은 극장을 떠나지 않는다. 모로의 현장 대사는 모두 생략해도 필수 사실과 진행이 남는다.

**피드백과 재확인:** 먼저 수리소를 마쳤어도 역의 이중 표지가 완성될 수 있도록, 역에서 빌려 쓰는 행사 받침의 출처를 본문에 넣었다. 사용한 표지를 마지막에 거두는 장면까지 읽었다.

## 조합 대조

원고의 엔딩 우선순위 표를 읽어 임시 분석으로 가능한 엔딩 조합을 열거했다. 게임 코드를 만들거나 실행 상태머신에 연결하지 않았다.

| 확인 범위 | 결과 | 의미와 한계 |
| --- | --- | --- |
| 1편 6엔딩 × 중간 세 편 각 4엔딩 | 384개 엔딩 조합 | 모두 1편 시작·5편 종료, 중간 세 편을 각각 한 번 방문 |
| 방문 순서 | 6종, 각 순서에 64개 조합 | 순서가 하나로 고정되지 않음 |
| 이미 방문한 우선 목적지 | 192회 건너뜀 | 미방문 목적지로 이어져 반복 방문 없음 |
| 중간편 엔딩명과 우선순위 표 | 12개 일치 | 이름 오기로 연결이 끊기는 항목 없음 |
| 최종편의 준비물 회수 문단 | 2·3·4편 각 4결과, 합계 12개 존재 | 모든 결말의 안내·신호·장비를 개별 언급함 |
| 마지막 방향 4개 × 실행 2개 | 8개 마무리 행동 원고 | 384개에 결합하면 3,072개 엔딩 수준 조합. 문학적 품질을 전부 자동 검증한 수치는 아님 |

이 열거는 **편 사이 진행의 완결성**을 확인한다. 모든 조사 선택 조합의 대사를 자동 합성하거나, 소지품·동시 역할·재미를 프로그램으로 증명한 것이 아니다. 인과관계와 조건부 문장은 위 여섯 읽기 경로 및 아래 보조 점검으로 확인했다.

## 보조 점검

- 각 중간 편의 조사 A~D 본문, 판단 정답과 오답 설명, 결말 A~D를 따로 읽었다. 모든 조사를 한 경로에서 한 것처럼 합치지 않았다.
- 모로 동행/비동행, 방전 뒤 다음 날 충전, 접속부 봉인 유지를 나눠 읽었다.
- 1편 원본 장부의 온전함/잉크 손실/밀봉 후 개봉을 구분했다. 새 편 자료로 잉크를 복원하는 문장은 없다.
- 최종 준비물은 조명 없음+음원 없음+개인 약도 없음 경로도 읽었다. 이 경우 사람 안내와 손·말 신호로 낮에 진행한다.
- 마지막 네 방향의 두 실행 문단을 모두 읽었다. ‘다음에 하자’만 있고 이번 모임이 없는 결말은 남기지 않았다.
- 극장을 처음 방문하는 순서에서 다른 장소의 결과를 알고 말하지 않는지 확인했다. 다른 중간 편도 같은 기준을 적용했다.
