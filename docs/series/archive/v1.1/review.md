# 비평과 수정 기록

**2026-10-28 · 초안 v1.0 → 수정 원고 v1.1**

평가는 작성자의 직접 읽기와 원고 기반 모의 진행이다. 별도 독자·플레이어의 피드백을 받은 것으로 쓰지 않는다. 게임 구현·새 장면의 브라우저 플레이는 수행하지 않았다.

## 2. 수정 후 다시 읽은 기준

### 큰 테마가 실제 행동으로 이어지는가

1편에서는 종이배를 돌려받을 사람의 뜻을 확인한다. 2편에서는 물건의 옛 주소와 지금 걸어갈 길을 나눈다. 3편에서는 좋은 녹음을 재생하는 것과 사람을 기다리는 일을 나눈다. 4편에서는 원형 사진과 현재 용도를 나눈다. 5편에서는 이 결과를 가지고 실제 한 번 출발하고 돌아온다.

같은 주장을 인물들이 번갈아 말하게 하기보다, 표지판을 돌리고·의자를 옮기고·빛을 낮추고·뒤쪽 신호를 기다리는 행위로 회수했다.

### 선택이 다음 편에 남는가

중간 세 편의 엔딩 12개는 다음 방문 선호와 최종편의 실행 수단을 바꾼다. 단서 조사와 판단 결과는 해당 편에서 직접 시험할지 담당자의 도움으로 시험할지를 바꾼다. 영구 실패 점수는 없다.

단, 조사 준비와 최종 결말은 자유롭게 조합한다. 조사 A를 했으니 마지막도 A여야 한다고 강요하지 않는다. 조사 결과를 바꿔 생각할 수 있는 구조다.

### 모든 이야기를 거치는가

[읽기 기록](walkthroughs.md)의 여섯 방문 순서와 엔딩 수준 384개 열거에서 중복·누락·조기 최종편 진입은 없었다. 이 수치는 분기 규칙에 대한 확인이다. 문장이 모든 조합에서 재미있다는 검증은 아니다.

### 1편을 무효로 만들지 않는가

늦게 고친 배가 당일 온전한 배였다고 바뀌지 않는다. 밀봉 후 개봉도 첫 모임을 되돌리지 않는다. 잉크를 잃은 장부는 복원되지 않는다. 잠든 모로는 실제 충전 장면 뒤에만 말한다. 봉인과 동행은 별개다. 윤서의 시정 책임을 새 모임의 성공으로 없애지 않는다.

## 3. 남은 한계

- 1편은 침수 구조의 긴장이 강하고 중간편은 생활 미스터리와 인물 변화가 중심이다. 후속편에서도 같은 위기 강도를 기대하는 독자에게는 차분하게 느껴질 수 있다. 새 범죄·재난을 억지로 추가하지 않고 이번 원고의 방향으로 남겼다.
- 중간편은 주요 결정이 세 번이고 기존 1편은 열한 번이다. 다섯 편을 같은 길이로 맞추지 않았다. 실제 읽기와 토론 시간을 측정하기 전 플레이 분량을 확정하지 않는다.
- 판단 오답은 설명과 동행으로 복구돼 엔딩이 막히지 않는다. 접근성은 좋지만, 실패의 긴장감이 약할 수 있다. 이를 검증하지 않고 난도가 적절하다고 단정하지 않는다.
- 새 이야기의 재미·몰입·반복 플레이 의향은 작성자의 자기 검토만으로 확정할 수 없다. 현재 완료 범위는 전체 집필, 직접 읽기·모의 진행, 인과·상태·분기의 수정이다.

다음 검토를 한다면 사람에게 먼저 한 경로만 읽게 하고 ‘다음 장소에 왜 가는지 설명할 수 있는가’, ‘마지막 선택 전에 각 방법의 차이를 예상하는가’, ‘같은 이야기를 반복한다고 느낀 부분이 있는가’를 확인한다. 게임 개발은 별도 요청 시 진행한다.
